## 1. 이 도구가 하는 일 (한 문단)

P&ID PDF 를 읽어 **계기·밸브 리스트**를 만든다.  입력은 도면 PDF 와 발주처의
**빈 양식**뿐이다.  심볼 검출 · 수량 · 스코프(공급 주체)는 **규칙만** 쓰고
LLM 을 쓰지 않는다.  판정에 쓰는 값은 그 도면의 **범례 · NOTES · 타이틀블록**
에서 런타임에 읽는다.  읽히지 않으면 **비워 두고 사유를 남긴다** — 지어내지
않는다.  사람은 검토 UI 에서 사유가 붙은 칸만 보면 된다.

```
AL NOUF1   지문 fb85b039 · 1037행 · Q'ty 1931
           축1 99.3/70.5 · 축2 99.3/94.4 · 양식 885/76/23

```

* 지문의 재료는 **행 아홉 칸**(`key` `tab` `type` `qty` `valve_type`
  `vendor_supply` `scope` `needs_review` `rect`) + `multipliers` + `legend`
  + 글리프 문자다.  `tag_no` · `description` · `evidence_tier` · `unit_notes`
  · `face_marks` 는 **지문 밖**이다.
* 지문이 움직였는데 검출을 안 바꿨으면 **원인을 칸 단위로 규명하기 전에 다음
  단계로 가지 않는다** (29회차 [B] 가 그 절차의 본보기).

  **행은 한 칸도 안 움직였다.**  이것을 숨기는 쪽이 정의 변경이다.

## 6. 구조 — 판정이 일어나는 **단 하나의 자리**들

같은 판정을 두 곳에서 하면 언젠가 갈린다.  아래는 "여기 하나" 로 못박아 둔 것들이다.

| 판정 | 한 곳 |
| --- | --- |
| 마크 **자리** | `detect_symbols.in_mark_window` |
| 마크 **소유자** | `detect_symbols._mark_gap` (유클리드) |
| 마크가 **심볼 글자인가** | `detect_symbols.on_bubble_face` (30회차) |
| SCOPE 한 값의 뜻 (화면) | `app.js` `scopeFacts` / (서버) `excel_out.in_client_scope` |
| 오버레이 색 | `pipeline._layers` — SCOPE 열과 **같은 값**을 읽는다 |
| 일괄 적용 사정거리 | `app.js` `sameSentence` |
| config 재바인딩 | `pipeline._rebind_config` (`_reconfigure` 와 되돌리기가 공유) |
| 측정축 정의 | `spike/accuracy.py` `AXES` (축1·축2) · `spike/identification.py` (축3) |
| 회귀 프로젝트 목록 | `spike/projects_3p.json` (**한 항목 추가가 프로젝트 추가**) |

**파이프라인 순서** (`pipeline.analyse`)
```
open_pdf → _fit_layout(도면에서 재고 낯선 프로필이면 얹는다) → titleblock_glyphs
        → titleblocks(못 읽으면 TitleBlockUnreadable) → legend_rules(없으면 LegendUnavailable)
        → layout(가장 비싸다 · 전체의 55~80%) → 장마다 instruments/valves
        → describe → rows → store
```
`analyse` 는 `_own_config` 로 감싸여 있어 **이 분석이 바꾼 config 가 다음
분석으로 새지 않는다** (22회차 · 실패해도 되돌린다).

## 7. 새 문서(다섯째 프로젝트)가 왔을 때

1. `docs/new_form_checklist.md` 절차대로 한 번 올려 `GET /jobs/{id}/measured_config`
   를 받는다.  `project_*.yaml` 을 만들고 **이력 표 여섯 칸만 손으로** 잰다.
2. `spike/projects_3p.json` 에 **한 항목**을 더하고 회귀를 돌린다.
3. **24회차가 남긴 재확인 목록 넷**을 본다: ① 노트 열 안쪽 괘선이 있는가
   ② 머리글 행이 개정 행보다 몇 % 높은가(빈 띠 유지) ③ 이력 띠가 둘인가
   ④ REV 칸에 개정 삼각형을 그리는가.
4. **30회차가 더한 것 둘**: ⑤ 개정 표기가 글자인가 숫자인가, 부개정(`A1`)이
   있는가 ⑥ 글자가 SHX(획)인가 — `page.get_text()` 가 비면 주석을 본다.
5. 등급을 판정한다 (`app/engine/tags.py`) — 태그가 인쇄돼 있으면 1급이다.
   **단 SCOPE 는 언제나 2급(별표·NOTES)이다** (§10-7).
