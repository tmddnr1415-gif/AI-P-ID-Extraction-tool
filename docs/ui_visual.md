# 화면 — 톤·색·진행 표시 (2회차)

기능은 §[A-2] 하나만 늘었습니다.  나머지는 이미 있던 것을 다르게 그린 것입니다.
수치는 전부 이 저장소에서 실제로 재거나 브라우저에서 읽은 값입니다.

## 1. 진행 표시 — 무엇이 이미 있었나

| 값 | 수정 전 | 지금 |
| --- | --- | --- |
| PDF 쪽수 | **아무 데서도 세지 않음** | 업로드 요청에서 `pymupdf` 로 셈 (58장 문서 **2.1~2.9ms**) |
| 진행률 분수 | 있었음 (`done / (쪽수+6)`) | 그대로 |
| 진행 장수 | 없음 — 메시지 문자열 `page 33 of 58` 뿐이고 그건 **쪽 번호**이지 진행 수가 아님 | `sheets_done / sheets_total` 로 실려 옴 |
| 단계 이름 | 영어 원문이 그대로 화면에 나감 | `STAGE_KO` 로 옮김.  모르는 값은 **그대로** 씀 |
| 소요 시간 | 없음 | `started_at` · `finished_at` 차이 |

**수정 전 실측**: 58장 PDF 를 놓고 80초 동안 1초 간격으로 화면을 읽었더니 진행
메시지가 **80번 중 79번 `starting`** 이었고, 13초 시점과 60초 시점의 캡처가
**바이트까지 같았습니다**.  화면 전체 글자가 `분석 중 / starting` 이었습니다.

원인은 파이프라인 순서입니다 — 실측:

```
open_pdf   2.3s
layout   185.1s      <- 첫 장을 읽기 전에 끝나야 하는 단계
(전체 서버 왕복 309.8s)
```

`layout` 은 `derive_layout.derive` 로, 문서 전체에서 프레임·타이틀블록 셀·파선
기하·벤더 표기를 재는 단계입니다.  **순서는 바꾸지 않았습니다** (금지 사항).
대신 그 단계가 자기 이름을 말하게 했습니다: `say(0, …, "opening the document")`
와 `say(0, …, "measuring the sheet")` 두 줄이 늘었고, 화면에는 "도면 치수를 재는
중 — 이 단계가 가장 깁니다" 로 나옵니다.  첫 화면의 소요 안내도 그 사실을 적습니다.

**분모는 58 이 아니라 52 입니다.**  분석이 걷는 것은 `page_kind == PID` 이면서
분석 범위인 도면뿐이고, 이 문서에서는 58쪽 중 **52장**입니다 (범례 4 · 도면목록 1 ·
범위 밖 1).  58 을 분모로 쓰면 마지막 장에서 52/58 에 멈춥니다.  그래서 쪽수는
"58장을 읽었습니다"로 따로 적고, 진행은 "도면 52장 중 23장 완료"로 적습니다.
분모는 파이프라인이 대상을 확정한 순간 한 번 실려 오고 그 뒤로 바뀌지 않습니다.

**남은 시간은 적지 않습니다.**  단계별 소요가 도면 한 장 0.3초 ↔ 사전 측정 185초로
60배 차이나므로 어떤 외삽도 추측입니다.

## 2. 색 세 층 — 서로를 먹지 않게

| 축 | 무엇으로 말하나 | 값 |
| --- | --- | --- |
| ① 범위(scope) | **색** | 포함 `#0a84ff` · 벤더 제외 `#ff9f0a` · SCT `#bf5af2` · 검토 `#ff453a` — **의미 대응 그대로** |
| ② 종류 | **파선** | 밸브 `5 3`, 계장 실선 / 제외는 얇게 `1.1` |
| ③ 개정 | **바깥 링** | 추가 `7 4` 파선 · 수정 `2 3` 파선, 상자에서 4px 밖 |

**있던 문제**: 개정이 검출 상자의 `stroke-width` 와 `stroke-dasharray` 를 덮어써서
(`.det.rev-added` 가 `.det.valve` 보다 뒤에 있어 이겼습니다) **추가된 밸브는 밸브의
파선을 잃고**, 제외 항목은 "제외는 얇게"를 잃었습니다.  개정을 자기 도형으로
떼어내 셋이 한 상자 안에서 같이 읽힙니다.

**"벤더 제외가 추가·수정이면 scope 가 사라진다"는 이 문서에서는 일어나지
않습니다** — 실측: 오버레이 항목 1,014개 중 `VENDOR_EXCLUDED` 는 **190개이고
전부 리스트 행이 없습니다**(`row: false`).  개정 상태는 리스트 행에만 붙으므로
벤더 제외 심볼은 추가·수정이 될 수 없습니다.  개정과 겹칠 수 있는 범위는
`INCLUDED` 782 · `REVIEW` 40 · `SCT` 2 입니다.  수정 전 캡처에서 세 상태가 전부
`#0a84ff` 로 보였던 것은 그 페이지의 행이 전부 포함 범위였기 때문입니다.

리스트에서 개정 세 상태는 **왼쪽 굵은 띠 + NO 앞 기호(＋ ≠ －) + 탈채도 색** 셋으로
말합니다.  색은 채도를 낮췄습니다: 추가 `#ffd60a → #d9a441`, 수정
`#30d158 → #79b585`, 삭제 `#e5484d → #e08a84`.  흑백에서도 기호와 띠가 남습니다.

등급은 **모양 · 글자 · 색** 세 가지를 같이 답니다 (`●` 도면 근거 있음 · `◇` 도착지 표기에서 유추 ·
`◐` 부분 · `○` 없음 · `×` 생략 · `✎` 직접 입력).  색을 못 보아도 앞의 둘이 남습니다.

## 2-1. 크림 톤으로 옮긴 뒤 (이 회차)

배경을 `#f7f2e6` 로 옮기면서 **어두운 판의 색을 그대로 쓸 수 없다**는 것이 실측으로
드러났습니다 — 개정 세 색이 전부 묻힙니다:

| 색 | 어두운 판 값 | 크림 위 대비 | 다시 고른 값 | 크림 위 대비 |
| --- | --- | ---: | --- | ---: |
| 개정 추가 | `#d9a441` | **2.01 미달** | `#8d6210` | **4.84 AA** |
| 개정 수정 | `#79b585` | **2.15 미달** | `#377349` | **5.07 AA** |
| 개정 삭제 | `#e08a84` | **2.31 미달** | `#ab3f3a` | **5.37 AA** |

같은 이유로 도면 선택 상자의 흰 테두리(`#fff`)도 흰 종이 위에서 사라져
`#4a3f33` + 흰 그림자로 바꿨습니다.

**scope 두 색은 값을 건드리지 않았습니다** — 의미 대응이 고정 사항이고, 이 둘은
크림이 아니라 **흰 도면 위**에 그려지므로 배경이 바뀌어도 대비가 달라지지 않습니다
(포함 3.65 · 벤더 제외 2.06, 이전 회차와 동일).

## 3. 톤 — 잰 대비

배경은 **따뜻한 중립 어두운 쪽**입니다.  도면이 흰 종이이고 화면의 절반을 차지하는데
밝은 배경으로 가면 뷰어와 껍데기의 경계가 사라지고, 오버레이·추적 색이 전부 흰
종이를 전제로 고른 값이라 다시 재야 합니다.  밝은 배경 안은 §5 에 후보로 둡니다.

| 쌍 | 비 | 판정 |
| --- | ---: | --- |
| 본문 `#f2eee7` on `#1b1917` | 15.16 | AA |
| 흐린 글자 `#a9a094` on 배경 | 6.80 | AA |
| 흐린 글자 on 패널 `#232019` | 6.30 | AA |
| 강조 `#4ea0ff` on 배경 | 6.51 | AA |
| 흰 글자 on 채운 버튼 `#0b6fd6` | 4.93 | AA |
| 조작 테두리 `#7a6f61` on 배경 | 3.57 | 1.4.11 통과 |
| 조작 테두리 on 패널 | 3.31 | 1.4.11 통과 |
| 개정 추가 `#d9a441` on 패널 | 7.23 | AA |
| 개정 수정 `#79b585` on 패널 | 6.78 | AA |
| 개정 삭제 `#e08a84` on 패널 | 6.30 | AA |
| 귀속 REVISION_GAP `#c9a2e6` on 배경 | 8.18 | AA |

**AA 에 못 미치는 두 값은 도면 위의 획입니다**: scope 포함 `#0a84ff` on 흰 종이
3.65, 벤더 제외 `#ff9f0a` on 흰 종이 2.06.  글자가 아니라 1.6px 테두리이고,
**scope 색의 의미 대응 변경은 이번 회차 금지 사항**이라 그대로 두었습니다.
바꾸려면 세 곳(리스트 · 도면 · Excel)을 같이 옮겨야 하므로 별도 회차입니다.

파랑은 이제 **하나**입니다.  예전에는 UI 강조 `#4c8dff` 와 도면의 "출력 포함"
`#0a84ff` 가 따로 있었습니다.

글자 크기는 네 단계입니다: 12 / 13 / 15 / 20.  숫자는 전부 `tabular-nums`.
본문 행간 1.5 → 1.6, 표 행간 1.45.

## 5. 판단이 필요한 것 — 후보만

1. **밝은 배경**.  지금은 따뜻한 어두운 쪽입니다.  밝게 가려면 뷰어 배경(흰 종이와
   껍데기의 경계) · 오버레이 4색 · 추적 4색 · 개정 3색을 전부 흰 바탕에서 다시
   재야 합니다.  비용은 이번 회차와 비슷하고, 얻는 것은 인쇄물과 같은 밝기입니다.
2. **scope 색의 대비**.  벤더 제외 `#ff9f0a` 는 흰 종이 위 2.06 입니다.  더 어두운
   주황(예: `#b06a00`, 4.6)으로 옮기면 AA 를 넘지만 **세 곳의 색 대응을 같이
   옮겨야 하고, 발주처가 이미 본 색입니다.**
3. **등급 배지의 형태**.  지금은 알약 + 글리프입니다.  대안은 왼쪽 세로 막대 +
   글자(더 조용하고 더 좁음)이며, 등급 열 폭이 약 30% 줄어듭니다.
