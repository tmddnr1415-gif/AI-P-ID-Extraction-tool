이 꾸러미는 hotfix40 까지 누적 위에 hotfix41 을 얹은 것입니다.  푸는 법은 이전과 같습니다
(프로그램 폴더에 그대로 덮어쓰기 · app/_data/ 와 data/ 는 들어 있지 않습니다).

1. QFE Description 에 변수어가 세 번 들어가던 것(`… PRESSURE PRESSURE PRESSURE`)을 고쳤습니다 —
   QFE 범례가 글자를 세 번 겹쳐 인쇄해 ISA 표의 뜻이 세 번 읽히던 것입니다 (1991행 중 1124행).
2. 검토자가 PDF 에 올린 메모(FreeText · `ESDV OUTLET TAG 중복 확인.` 같은 것)의 글자를 도면 글자로
   읽어 기기 라벨·Description 에 섞이던 것을 뺐습니다 (AutoCAD SHX 글자 주석은 그대로 읽습니다).
3. 머리줄 '변경 내역 Excel' — 추가 · 수정(바뀐 칸 전→후) · 삭제(근거) · 장 변경 · 요약 다섯 시트.
4. 나란히 보기에서 오른쪽 장을 사람이 고를 수 있습니다 (직전에만 있는 장도) · Alt+←/→ 로 변경 이동.
5. 회귀 기준선이 바뀝니다 — AL NOUF1 1137 → 1133 (메모 `HV -> MOV` 가 만들던 REVIEW 행 4) · QFE 지문.
6. 다시 분석해야 1·2 가 결과에 반영됩니다 (이미 분석한 결과는 옛 문장이 남습니다).
