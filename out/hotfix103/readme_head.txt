이번에 들어간 것 — LOGIC
  (L43) 순차 동작 중 파란 활성 선이 두 행쯤 어긋나 보이던 것을 고쳤습니다.
        시트를 옮길 때 그림이 바뀐 뒤에 선을 그립니다.  시트 바꾸기도 더 가볍습니다.
  (L44) 매크로 블록 '내부 동작 보기' 새 창이 실제 시트의 행과 값으로 보입니다.
        · Typical 행 옆에 실제 행 번호 (예: ← BL11_G131-14)
        · 부모 시트에서 준 신호가 새 창에 그대로 켜집니다 (펄스 신호도)
        · 새 창에서 입력 행을 누르면 부모 시트의 그 실제 행에 들어갑니다.

  1) apply_to_PID_dev.bat 더블클릭
  2) 분석이 돌고 있지 않을 때  apply_to_PID_ops.bat 더블클릭

       → "[완료] 서버가 다시 떴습니다 — 업데이트 hotfix103" 가 나오면 됩니다
  3) 대시보드에서 LOGIC 을 다시 열고 Ctrl+F5
  4) 서버 창 파일(run_lan_service.bat)을 이미 새 것으로 바꿨으면 건너뛰세요.
     아직이면 zip 의 files 폴더에 있는 run_lan_service.bat 을 C:\Claude\PID 에 넣습니다
     (서버 창을 모두 닫은 뒤, 옛 파일은 .old 로).
