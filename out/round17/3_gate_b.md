# 17회차 [B] 게이트 — 미검출을 풀면 정밀도가 어디로 가나

**결론: 네 안 모두 축2(SCT) 정밀도를 88.4% 아래로 내린다.  [B] 를 구현하지
않고 [C] 로 간다.**  프롬프트 [B-2] 의 게이트 그대로다.

측정은 **코드를 고치지 않고** 했다 — 밸브 검출기 한 번 + 기존 `base.json`
1029행에 합성 행을 더해 같은 채점기(`spike/accuracy.py` 의 `score`)로 쟀다.
전량 분석을 추가로 돌리지 않았다.

## 기준선

```
축1 (전량)  재현율 99.3% / 정밀도 70.50%   FP 249 · FN 4
축2 (SCT)   재현율 99.3% / 정밀도 88.41%   FP  78 · FN 4
```

## B-1 ②③ 세 안 — 늘어나는 행과 지표 이동

**⚠ 어느 탭에 넣느냐가 지표를 전부 결정한다.**  채점은 FIELD·MOV·BFV 세
리스트만 보고, PNEUMATIC 탭(=CZF 자리)은 **채점 대상이 아니다**.  그래서 두
배분 정책을 나란히 쟀다.

| 안 | 행 +N | Q'ty +N | 탭 배분 | 축1 정밀도 | 축2 정밀도 |
| --- | ---: | ---: | --- | --- | --- |
| **(a) 태그 있으면 행** | +89 | +193 | 몸체 종류 (MOV 68·PNEU 16·BFV 5) | 70.5 → **68.9** | 88.4 → **86.1** |
| | | | 전부 PNEUMATIC | 70.5 (안 잼) | 88.4 (안 잼) |
| **(b) 범례 자기작동(PSV·PRV·BPRV)만** | +61 | +126 | 몸체 종류 (MOV 47·PNEU 9·BFV 5) | 70.5 → **69.8** | 88.4 → **87.4** |
| | | | 전부 PNEUMATIC | 70.5 (안 잼) | 88.4 (안 잼) |
| **(c) 범례가 액추에이터와 함께 정의한 태그만** | +28 | +67 | 몸체 종류 (MOV 21·PNEU 7) | 70.5 → **69.7** | 88.4 → **87.1** |
| | | | 전부 PNEUMATIC | 70.5 (안 잼) | 88.4 (안 잼) |
| **(c′) (c) + 범례가 말한 액추에이터 부여** | +28 | +67 | MOV 4 · PNEUMATIC 24 | 70.5 → **70.2** | 88.4 → **87.9** |

**재현율은 네 안 전부 99.3% 그대로이고 FN 도 4 그대로다.**

**(c) 를 만든 근거**: 범례 p4 는 `MOV` 를 모터와, `XV OR NRV`·`PCV`·`FCV`·
`TCV`·`LCV` 를 공압 심볼과 **함께** 그린다 (`1. ON-OFF MOV TYPE TYPICAL` ·
`2. PNEUMATIC SHUT-OFF VALVE TYPICAL` · `1. PNEUMATIC CONTROL VALVE DETAIL`).
범례 p3 은 `PSV`·`PRV`·`BPRV` 를 **자기작동 열**에 둔다.  즉 "태그가
액추에이터를 말하는가" 는 도면이 아니라 **범례가 답한다** — 태그명 분기가
아니라 범례 유도다.

**"전부 PNEUMATIC 탭" 은 게이트 통과가 아니다.**  정밀도가 안 움직이는 것은
맞아서가 아니라 **그 탭이 채점되지 않기 때문**이다 (CZF 미수령).  그것을
통과로 읽으면 측정 정의를 피해 수치를 좋게 만드는 것이므로 §2.2 위반이다.

## 왜 재현율이 하나도 안 오르나 — 정답지의 구조

정답지의 액추에이터 열에 **빈칸이 없다**: CZH 63행 전부 `MOTOR`, CZI 19행
전부 액추에이터가 있다.  액추에이터 없이 넣은 행은 어느 사람 행과도 짝이
되지 않아 **전부 FP** 다.

**FN 4건이 어디 있는지도 확인했다** — 밸브와 거의 무관하다.

| FN | 도면 | 그 도면의 NONE 몸체 |
| --- | --- | --- |
| FIELD:PIT ×1 | `D00P-00PAB10-M05-0001` | 77개 · 태그 있는 것 **0** |
| FIELD:PIT ×1 | `D00P-00PAB10-M05-0002` | 57개 · 태그 0 |
| FIELD:FE ×1 | `D00P-11LAC10-M05-0001` | 115개 (계기 FN) |
| **BFV:PNEUMATIC ×1** | `D00P-00PAB10-M05-0003` | 26개 · 태그 **0** |

유일한 밸브 FN 은 어느 안으로도 회수되지 않는다.  그 장의 BUTTERFLY 몸체는
4개인데 3개는 MOTOR(이미 BFV 행)이고 1개는 NONE·태그 없음 — 렌더로 보면
**수동 나비 밸브**(활 모양 + 원, 스템에 아무것도 없음)다.  즉 그 FN 은 문턱
문제가 아니라 **액추에이터 판독 문제**이고, 문턱을 낮춰도 태그가 없어 안
들어온다.

## B-1 ④ CZF 26행과의 관계 — 여기서 판정이 멈춘다

`docs/design.md §1.2` 실측: **CZF(Pneumatic Valve) 유효행 26 · 항목 26 ·
Q'ty 81.**  우리 PNEUMATIC 탭은 45행(SCT 25)이고 **양식 미수령**이라 Excel
로 나가지 않는다.

판정할 수 없는 부분은 셋이다.

1. **위 표의 "전부 PNEUMATIC" 줄 전체.**  CZF 를 받는 순간 그 칸들이 전부
   실측값으로 바뀌고, 그때 비로소 (a)/(b)/(c) 의 우열이 갈린다.
2. **자기작동 61행(PSV 59·PRV 1·BPRV 1)의 갈 곳.**  CZF 는 이름이
   *Pneumatic* Valve 이고 26행뿐이라 PSV 59행이 거기 들어간다고 보기 어렵다.
   그렇다면 **네 번째 리스트가 따로 있다는 뜻**인데 그 존재 자체가 미확인이다.
3. **10회차 [D] 의 NRV 배분** — 사유가 같다.

## p8 MOV — 잉크 걸림을 밸브 경로에 넣으면

16회차 ㉢(개정 클라우드의 빨간 호)과 같은 뿌리다.  `_round_paths` 는 곡선만
으로 된 path 를 모으고 그것이 `_arc_above`(다이어프램 돔) 판정에 쓰인다.

**58장 전수 영향은 아주 좁다** (측정만 하고 코드는 고치지 않았다):

```
곡선 path 23,083개 중 잉크가 아닌 것 15,936개 (45장)
그런데 몸체는 2,813 → 2,813 (사라진 것 0 · 새로 생긴 것 0)
바뀐 몸체는 3개뿐:
  p8  (901.0,669.7)  DIAPHRAGM/MOTOR/MOV → GATE/MOTOR/MOV   ← 행이 된다
  p47 (634.1,312.8)  DIAPHRAGM/NONE      → GATE/NONE        (EXCLUDED 그대로)
  p47 (634.1,1201.1) DIAPHRAGM/NONE      → GATE/NONE        (EXCLUDED 그대로)
산출물 갈래: EXCLUDED 2669→2668 · MOV 76→77 · 나머지 불변
```

**그런데 그 +1 이 게이트를 깬다.**

```
축2 정밀도 88.41% → 88.28%   (FP 78 → 79)
축1 정밀도 70.50% → 70.41%
재현율은 둘 다 99.3% 그대로 · FN 4 그대로
```

이유가 중요하다 — **발주처 CZH 는 그 도면에 MOTOR 를 5행 갖고 있고 우리는
이미 6행을 내고 있다.**  7번째를 넣으면 순수 FP 다.

```
CZH  D00P-10LBC50-M05-0001 · MOTOR :  사람 5  ·  우리 6  → +1 하면 7
```

**즉 피드백(“p8 의 MOV 가 안 나왔다”)과 정답지(“그 장의 MOV 는 5개”)가 서로
다른 말을 한다.**  우리 6행 중 하나가 잘못된 MOV 이고 이 몸체가 진짜 빠진
것일 수도 있는데, 채점이 칸마다 `min(사람, 프로그램)` 이라 **어느 행이
틀렸는지는 말해 주지 않는다** (§ 정확도 절의 전제).

**실무 판단 대상이다** (§14.3): 발주처가 그 장에서 MOV 를 몇 개로 보는가.
답을 받기 전에는 게이트를 지켜 **구현하지 않는다.**

## p20 — 심볼 미지정이라 손대지 않는다

16회차 조사 그대로다.  p20 은 38행을 내고, 그 장에서 행이 안 된 밸브 태그는
셋이다.

| 태그 | 몸체/액추에이터 | 사유 |
| --- | --- | --- |
| PSV | CHECK/NONE | 자기작동 |
| PSV | GLOBE/NONE | 자기작동 |
| MOV | GLOBE/NONE | **태그가 엉뚱한 몸체에 붙었다** |

MOV 버블 `[1468.4, 641.0, 1536.4, 663.6]` 이 가리키는 실물은 M 이 달린
`[1451.4, 689.9, 1468.4, 699.8]`(GATE/MOTOR)이고 **그 몸체는 태그 없이 이미
MOV 행으로 나가 있다.**  `attach_tags` 가 **가장 가까운 몸체**에 태그를
주므로(리더선을 따라가지 않는다) 51.0pt 떨어진 수동 GLOBE 가 61.3pt 떨어진
진짜 몸체를 이겼다.  **반경을 늘리면 더 나빠진다** — 더 많은 남의 몸체가
후보가 된다.
