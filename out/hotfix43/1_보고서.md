# hotfix43 — 개정의 '수정' 은 태그가 달라진 행뿐 (2026-10-06)

사용자: *"이전 pid 대비 최신 pid 수정 변경 사항 식별이 이상한 것 같다.  위치변경이 아니라,
tag number 변경 또는 기존에 없었던 tag 가 추가되었거나 삭제되었을 때만 수정사항으로 간주한다."*

## 1. 원인

`app/revisions.py` `compare()` 가 `COMPARED_FIELDS` 여덟 칸(type · valve_type · qty · system ·
vendor_supply · scope · tag_no · description) 중 **어느 하나라도** 다르면 `MODIFIED` 로 두고 있었다.
QFE 260112 → 260326 실측(hotfix38): 수정 458 중 **411 이 Description 재생성** — 도면이 바뀐 것이 아니라
우리 문장(순번 A→B · 계통명 꼬리)이 바뀐 것이다.  그 밖에 system 95 · scope 11 · qty 2.
자리 이동은 처음부터 상태가 아니었다 (`moved_pt` 기록만).

## 2. 고친 것

| 자리 | 전 | 후 |
| --- | --- | --- |
| `revisions.STATE_FIELDS` · `_revision_state` | 여덟 칸 어느 것이든 다르면 수정 | **`tag_no` 하나** — 태그가 달라졌을 때만 수정 (빈칸 → 태그 · 태그 → 빈칸 포함) |
| `states[...]["changed"]` | 다른 칸 전부 | 태그 변경만 (`{field: tag_no, was, now}`) |
| `states[...]["field_diffs"]` (신설) | — | 그 밖에 값이 다른 칸 — **기록만**, 상태에 안 씀.  장부 이력 · DB `revision_state.diffs_json` (가산 열) |
| `excel_out.revision_remark` | `Rev.A 대비 수정 (description)` | `Rev.A 대비 수정 (태그 X → Y)` |
| 변경 내역 Excel `수정` 시트 | 바뀐 칸 · 자리 이동 | **바뀐 태그** · 그 밖에 값이 다른 칸(참고) · 자리 이동 |
| 화면 | `수정만` · MOD 툴팁 "바뀐 칸 …" | `수정만 (태그 바뀜)` · 툴팁/변경 목록 `태그 X → Y` · 근거 패널 **"값이 다른 칸 (개정 판정에는 쓰지 않음)"** · 변경 없음 행에 `N pt 이동 (자리 이동은 수정이 아님)` |

추가(`ADDED`)·삭제 후보(`DELETED_CANDIDATE`)는 그대로다 — 짝이 안 선 행·기록이고 태그 문서에서는 곧
"없던 태그 · 사라진 태그" 다.  짝짓기(태그 유일 → 기하 → 태그 다른 쌍)도 바꾸지 않았다.
