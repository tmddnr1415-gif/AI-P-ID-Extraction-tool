## 물음 넷에 답한다

### 1. 오버레이가 도면과 어긋난 장이 있는가 — **없다**

맞춤 배율 28장 전부에서 상자가 심볼 위에 있고, **세 단계 확대한 캡처**가
그것을 눈으로 확인해 준다 (`p6_zoom.png`):

* **UAD p6** — 빨간 상자 셋이 `PIT` 버블 **윤곽에 정확히** 맞는다.
  선택한 행은 굵은 상자 + 파란 배관 + 빨간 X(끊긴 지점)까지 제자리다.
* **SADARA p6** — 선택한 `TIT` 버블을 상자가 감싸고, 그 **위에 인쇄된 `(**)`**
  까지 보인다 (별표가 상자 밖이라는 것도 그대로 보인다).

**A3 · `/Rotate 270` 이 A1 과 같은 정확도다** — 23회차가 "회전 정규화는 축척을
넘는다" 고 적은 것을 표시 쪽에서도 확인했다.  ⚠ 이번에 세어 보니 **AL NOUF1 도
58장 중 2장이 `/Rotate 270`** 이고 **SADARA 는 A0(3370×2384) 9장 전부 회전**이다 —
"A1·A3 만 보았다" 는 이 회차 프롬프트의 전제가 실제와 다르다 (아래 [D] ① 참조).  ⚠ 다만 이것은 **눈으로 본
확인**이고 픽셀 단위 자동 대조가 아니다.

### 2. 범례 패널 숫자가 화면에 보이는 것과 맞는가 — **맞는다(세는 대상과는)**

28장 전부에서 **범례 네 칸의 합 = 표시된 상자 수 = 그리드 행 수**다
(p12 의 20↔19 는 위에 적은 캡처 방법 탓).  12회차가 고친 "라벨과 세는 대상이
다르다" 는 재발하지 않았다.

### 3. 색이 SCOPE 와 같은 값을 읽는가 — **읽는다.  그런데 SCOPE 보다 센 것이 있다**

`pipeline.py:930` 한 줄이 답이다:

```python
scope = (SCOPE_REVIEW if r.needs_review else
         SCOPE_VENDOR if str(r.scope or "").startswith(COL_VENDOR) else
         SCOPE_SCT if r.scope == COL_SCT else SCOPE_INCLUDED)
```

**검토 사유가 하나라도 붙으면 SCOPE 색이 덮인다.**  그래서:

| 프로젝트 | 실제 SCOPE | 도면 위 색 | 덮은 사유 |
| --- | --- | --- | --- |
| AL NOUF1 | SCT 715 · VENDOR 322 | **보인다** | 검토 152/1037 |
| TC2 | SCT 434 · VENDOR 173 | 8장 중 **5장 보인다** | 검토 245/607 (그중 `MULTIPLIER_FROM_CONFIG` 203) |
| **SADARA** | **SCT 75 · VENDOR 7** | **한 장도 안 보인다** | 검토 **82/82** (`MULTIPLIER_UNDEFINED` 82) |
| **UAD** | **SCT 92 · VENDOR 57** | **한 장도 안 보인다** | 검토 **149/149** (`MULTIPLIER_FROM_CONFIG` 149) |

**★ 이것이 이 회차의 발견이다.**  SADARA·UAD 는 SCOPE 를 **판정해 놓고도**
도면 위에서는 전부 빨강이고, 범례는 `SCT 공급 범위 0` 이라고 적는다 —
**그 행들은 SCT 인데** 화면은 0 이라고 말한다.  색이 틀린 것이 아니라
**한 색이 다른 색을 가린다**.  원인은 31회차가 만든 승수 사유가 두 문서에서
**전량**에 붙기 때문이고, 사람이 승수를 한 번 답하면 사라진다 — 즉
**"값이 안 들어온 상태" 가 표시까지 덮는다.**

## 이 캡처가 답하지 못하는 것

* "도면에 실제로 있는 계기 수" 를 세지 않았다 — 미검출은 [30회차 C] 가 UAD 에서
  36건으로 세어 두었고, **이 캡처는 검출된 것이 제자리에 그려지는가**만 본다.
* 확대 캡처는 장마다 하나(첫 장)뿐이다.
* ⚠ 확대 단계를 넣은 재실행에서 UAD p31 의 SVG 노드가 8 → 13 으로 늘었다.
  **선택한 행의 배관 층(파랑·초록·노랑·빨강)이 더해진 것**이고 검출과 무관하다 —
  표의 숫자는 선택 이전 값이다.
