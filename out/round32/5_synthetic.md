도구 `spike/make_synthetic.py` (만들기) · `spike/run_synthetic.py` (돌리기).
**재료는 AL NOUF1 의 범례 4장 + P&ID 2장**이고 파일마다 **한 축만** 바꿨다.
엔진은 한 줄도 고치지 않았다.

⚠ **합성 도면은 저장소에 커밋하지 않는다.**  프롬프트는 "실제 발주처 도면이
아니므로 커밋해도 된다" 고 했지만, 내가 만든 방식은 **발주처 도면의 쪽을
재료로 쓴다** — 내용이 그대로 들어간다.  그래서 `data/*.pdf` 와 같은 규칙을
받고(`.gitignore`), **만드는 스크립트와 README 만** 커밋한다.  (프롬프트의
전제와 다른 판단이므로 여기 적어 둔다.)

## 읽을 수 있는 것

### ⑤ 가 대조군이다 — **여섯 장짜리 발췌는 잘 돈다**

범례를 **마지막 장으로 옮겨도** 78행이 나온다.  15회차가 "범례는 인쇄된
머리말로 찾는다" 고 적은 것이 실제로 자리와 무관하다는 뜻이고, 동시에
**①②③④가 멈춘 것이 "6장짜리라서" 가 아니라는 증거**다 (같은 6장 구성).

### ①②③④ — 전부 **시끄럽게** 멈춘다.  조용한 0행은 없다

넷 다 `TitleBlockUnreadable` 이고 문장이 구체적이다 — 쪽 크기, 도면번호 칸을
어디로 보고 있는지, 그 자리가 종이 밖인지 비어 있는지, 그리고 *이 회사 양식의
좌표를 재서 설정에 넣으면 된다* 까지.  **21회차가 만든 자리가 값을 한다.**

원인은 둘로 갈린다 (실측):

| | 유도 항목 수 | 타이틀블록 캡션 | 무엇이 일어났나 |
| --- | ---: | --- | --- |
| ⑤ 원본 그대로 | **21** | `dwg_no, project_name, project_no, title` 찾음 | 정상 |
| ③a `/Rotate 90` | **8** | **못 찾음** | 회전 정규화 뒤 타이틀블록 열이 다른 자리로 간다 |
| ①② 배율 | **0** | 못 찾음 | 배율이 바뀌면 칸을 하나도 못 잰다 |

**★ 그러나 이것을 "A0·A4 를 못 읽는다" 로 읽으면 틀린다.**  SADARA 는
**네이티브 A0**(3370×2384)이고 82행이 나온다.  내가 만든 ①②는 *A1 도면을
A0 종이에 다시 그린 것*이라 **글자 높이까지 같이 커지고 줄어든다** —
실제 A0 도면과 다른 물건이다.  ③(회전)은 원본 그대로 복사했으므로 그 축은
유효하고, **네이티브 `/Rotate 270` 문서 셋(TC2·UAD·SADARA)은 잘 도는데
0 도 문서에 회전을 씌우면 멈춘다** 는 것이 이 시험이 말하는 전부다.

### ⑥ 범례 없음 — 설계대로

`LegendUnavailable` 이 뜨고 **다음에 무엇을 하면 되는지**(범례 든 PDF 로 한 번
분석하면 프로필이 생긴다)까지 말한다.

## ★ ⑧b — 이 회차의 최대 발견: **1급 문서에 밸브가 있으면 분석이 죽는다**

태그 한 축만 바꿔 돌리자 분석이 **예외로 끝났다**:

```
AttributeError: 'str' object has no attribute 'update'
  app/pipeline.py:1042   r.evidence.setdefault("tag", {}).update(...)
```

충돌하는 두 자리가 같은 열쇠를 서로 다른 모양으로 쓴다:

| 자리 | 무엇을 쓰나 | 모양 |
| --- | --- | --- |
| `pipeline.py:3139` (밸브 행) | 도면이 그 밸브에 붙인 태그 문자열 | **`str`** (`''` · `'BPRV'` …) |
| `pipeline.py:1042` (29회차 1급 경로) | 태그 판정 근거를 얹는다 | **`dict`** 를 기대하고 `.update()` |

**UAD 가 지금 안 죽는 것은 우연이다.**  실측 — UAD 149행 중 밸브는 **3행**이고
`evidence["tag"]` 가 전부 문자열(`''`·`''`·`'BPRV'`)인데 **그 3행에 1급 태그가
하나도 안 붙었다**(0/3).  나머지 128행은 계기라 `dict` 로 들어간다.
**밸브 사각형 안에 태그가 인쇄된 1급 도면이 오면 그 자리에서 죽는다.**

* 합성 ⑧b 는 검출 사각형 **전부**에 태그를 찍었으므로 밸브에도 붙었고,
  그래서 121초 만에 죽었다.
* 죽는 방식도 나쁘다 — `LegendUnavailable`·`TitleBlockUnreadable` 같은
  **사유 있는 정지가 아니라** 맨 `AttributeError` 라, 화면에는
  `_failure_reason` 의 **일반 문구**가 간다 (무엇이 틀렸는지 말하지 못한다).
* **이 회차는 고치지 않는다** (엔진 수정 금지).  다음 회차 1순위 후보다.

## ⚠ 스스로 뒤집은 것 — 구성이 틀린 파일 둘

### ⑦ 이력 표를 **못 없앴다**

흰 사각형으로 덮으면 괘선이 내용 스트림에 남는다는 것을 알고 **클립**으로
바꿨는데, 클립도 **가리기만 하고 지우지 않는다**.  실측: 이력 띠 안 도형이
원본 248개 → 합성 **744개** (세 조각으로 나눠 그려 3배가 됐다).
그래서 ⑦의 "완주 46행" 은 *이력 표가 없을 때* 의 값이 아니라 *같은 내용을 세
번 그린 문서* 의 값이고, 행이 78 → 46 으로 준 것도 그 탓이다.
**이 파일은 아무 것도 증명하지 않는다.**

### ⑧ 두 축을 한꺼번에 바꿨다

A4 로 줄이면서 태그를 넣었더니 **타이틀블록에서 먼저 멈춰** 태그 판정에
닿지도 못했다 (3.0초).  게다가 P&ID 2장만 담아 범례도 없었다.
→ **태그 한 축만** 바꾼 ⑧b 를 따로 만들었다.

## 합성이 대표하지 못하는 것 (밝혀 둔다)

* **획(SHX)으로 그린 글자** — 배율 경로(`show_pdf_page`)는 **주석을 옮기지
  않는다**.  UAD 의 `AutoCAD SHX Text` 주석 10,729개 같은 것은 재현되지 않는다.
* **개정 클라우드 · 패키지 상자 · 도면 오탈자** — 재료 도면에 있는 것만 들어간다.
* **회전 원본 한 장** — 배율 경로에서 `/Rotate 270` 인 원본 p7 은 낱말이
  365 → 134 로 줄었다 (나머지 장은 378 → 378 · 658 → 658 로 **그대로**다).
  ⚠ 처음에 이것을 "배율 경로가 낱말을 잃는다" 고 적었는데 **쪽 번호를 잘못
  맞춘 내 실수**였고, 실제로 잃는 것은 회전된 원본 장뿐이다.
* **네이티브 종이 크기** — 위에 적은 대로, 다시 그린 것은 네이티브가 아니다.
