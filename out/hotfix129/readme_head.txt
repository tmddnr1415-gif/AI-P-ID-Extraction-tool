PID 업데이트 hotfix129 (2026-10-30) — LOGIC 화면이 업데이트 뒤에도 옛 화면으로 보이던 것 막기

무엇이 바뀌었나
- LOGIC 화면이 업데이트를 적용한 뒤에도 예전 화면으로 보일 수 있었습니다.  원인 두 가지를 고쳤습니다.
  · 브라우저가 LOGIC 화면 파일을 예전 것 그대로 다시 쓰던 문제.  이제 파일이 바뀌면 반드시 새 파일을 받습니다.
    (P&ID 첫 화면과 판넬 화면은 이미 이렇게 되어 있었는데 LOGIC 만 빠져 있었습니다.)
  · 업데이트하면서 서버를 다시 켜는 동안 화면이 '서버 꺼짐(절전모드)'을 기억하면, 다음에 열 때 보관해 둔 예전 화면을
    먼저 보여 주던 문제.  이제 화면을 열 때마다 서버에 먼저 물어봅니다.
- LOGIC 화면 오른쪽 아래에도 "업데이트 hotfix129" 가 작게 보입니다.
- LOGIC 기능은 hotfix128 과 같습니다 (최신 LOGIC 변경 L70~L78 전부):
  · 📘 시운전 — 시운전 단계별 동작 · 단계마다 시뮬레이션 · System Description(Word) 내보내기
  · 신호 처리 시뮬레이션 페이지 · 도면 연산자 '시뮬레이션에서 열기' · 연산자 계산 과정
  · 최종 명령에서 최초 입력까지 게이트 단계별로 거슬러 올라가기
  · 작도 — 꺾인 선 토막 끌어 옮기기 · 팔레트 잘림 고침 · 아미랄 그림 묶음(827장)
- P&ID · 판넬 · 도서검토는 hotfix128 과 같습니다.

적용
1. apply_to_PID_dev.bat → 확인 → apply_to_PID_ops.bat (서버 재시작 안내를 따르세요).
2. LOGIC 화면을 열고 오른쪽 아래 "업데이트 hotfix129" 를 확인하세요.
   위쪽 버튼에 "🖥 DCS 그래픽" 과 "📘 시운전" 이 둘 다 보이면 최신 LOGIC 입니다.
3. 오른쪽 아래 글이 안 보이면: 운영 서버가 재시작되지 않은 것입니다.  서버를 다시 켜고 Ctrl+F5 로 한 번 새로고침하세요.
   (이번 판부터는 그 뒤로 새로고침을 따로 하지 않아도 됩니다.)
