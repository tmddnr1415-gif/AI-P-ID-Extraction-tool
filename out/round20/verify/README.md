## 이번 검증에서만 나온 사실

- **7단계의 진입 경로는 `a.revrow` 다.**  `?job=` 로 URL 을 직접 열면 결과
  화면이 뜨지 않는다 (첫 화면 목록에서 눌러야 한다).  이것은 결함이 아니라
  13회차 설계 그대로이고, 검증 스크립트가 처음에 그것을 몰라 0행을 냈다.
- **11단계 UI 시험을 이 검증이 만든 DB 로 돌렸다.**  824행(SCOPE 없음)과
  1037행(SCOPE 있음)이 한 DB 에 있어 14회차가 요구한 세 갈래
  (SCT · 비SCT · legacy)가 전부 실제 데이터로 걸린다.
