hotfix56 — 분석 중에 대시보드가 "P&ID 서버가 꺼져 있습니다" 를 띄우던 것

[무엇이 문제였나]
분석이 "도면 치수를 재는 중" 일 때 서버 프로세스가 바빠 3초 안에 대답하지 못했습니다.
대시보드는 P&ID 메뉴를 누를 때마다 3초 안에 대답을 받아야 화면을 띄우므로,
서버가 켜져 있는데도 "꺼져 있습니다" 라고 말했습니다.
(이 저장소 실측 TC2 60장: 190초 동안 3초 초과 7번)

[고친 것]
분석을 서버와 다른 프로세스에서 돌립니다.  서버는 분석 중에도 바로 대답합니다
(같은 실측에서 0.00~0.01초).  판정 코드는 한 줄도 바뀌지 않았습니다.
덤: 분석이 메모리 부족으로 죽어도 서버는 살아 있고, 분석이 끝나면 메모리가 돌아옵니다.
