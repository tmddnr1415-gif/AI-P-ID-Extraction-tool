# 24회차 [B] — 세 문서의 개정 이력 표 실측

코드를 고치기 전에 세 문서에서 이력 표를 재고, **무엇이 세 문서에 걸쳐
성립하는지**만 규칙 후보로 남긴다.  도구는 `spike/hist_measure.py` ·
`spike/hist_rows_probe.py` · `spike/hist_shape_probe.py` ·
`spike/hist_cols_probe.py` · `spike/hist_gaps.py` 다.

## 1. 표가 어디에 있나

| | AL NOUF1 | SADARA | TC2 |
| --- | --- | --- | --- |
| 종이 | 2384 x 1684 (A1) | 3370 x 2384 | 1191 x 842 (A3) |
| 타이틀블록 열 x | 1969.5 | 2726.7 | 963.8 |
| 노트 열 안쪽 괘선 | 2330.3 | 3286.3 | **없음** (시트 가장자리 1162.3) |
| 이력 띠 y | 1257.5~1392.3 | 1645.9~1839.3 | 603.9~672.3 |
| 행 높이 | 16.74 / 16.80 | 24.00 / 24.10 | 8.40 / 8.52 |
| 이웃 띠(서명란) 행 높이 | 44.52 | 63.81 | 22.56 |
| 이력 캡션 인쇄 | **10/58 장만** (나머지 48장은 획으로 그린다) | 있음 | 있음 |
| `derive_layout` 의 캡션 찾기가 그것을 찾나 | **못 찾는다** | **못 찾는다** (0.1pt 반올림) | 찾는다 |
| REV 열 | 1969.5~1989.1 | 2726.7~2766.8 | 963.8~978.0 |
| REV 칸 안의 그림 | 글자만 | **개정 삼각형** | **개정 삼각형** |

## 2. 세 문서에 걸쳐 성립하는 것 — 규칙 후보

1. **이력 띠는 타이틀블록 열을 가로지르는 괘선 중 간격이 서로 같은 띠**이고,
   그런 띠는 두 개(이력 표 + 서명란)이며 **행 높이가 2~3배 갈린다.**
   촘촘한 쪽이 이력 표다 (16.74↔44.52 · 24.05↔63.81 · 8.52↔22.56).
2. **열은 그 띠를 세로로 가로지르는 괘선**이고 1열이 REV · 2열이 DATE 다.
   캡션을 인쇄하는 두 문서에서는 캡션이 그 열 안에 들어가 서로를 확인해 준다
   (SADARA `REV.` 2735.7~2757.9 ⊂ 2726.7~2766.8 · TC2 967.0~974.8 ⊂ 963.8~978.0).
3. **오른쪽 끝은 시트 가장자리가 아니라 노트 열의 안쪽 괘선**이다 — AL NOUF1 의
   이력 괘선은 2330.3 에서 멈추고 시트는 2345.3 이다.  TC2 는 안쪽 괘선이 없어
   가장자리가 답이다.

## 3. 성립하지 않는 것 — 규칙으로 쓰지 않은 것

| 후보 | 왜 안 되나 |
| --- | --- |
| 캡션(`REV. DATE`)으로 표를 찾기 | **세 문서 중 하나에서만 찾힌다** — AL NOUF1 은 58장 중 10장만 텍스트로 인쇄하고(48장은 획) SADARA 는 인쇄하는데 `_column_lines` 의 0.1pt 반올림이 같은 줄을 둘로 쪼개 놓친다.  1차로 삼으면 기준선 문서가 빠진다 |
| 종이 크기 비율로 좌표를 환산 | 23회차 §6 — 축척 보정은 답이 아니다 (금지 사항) |
| 아래에서 몇 번째 행 하는 식의 고정 위치 | TC2 는 장마다 띠 안 행 수가 갈린다 (7행 11장 · 8행 49장) |
| `hist_row_inset` 을 유도 | **그리지 않은 값이다.**  칸을 읽을 때 안쪽으로 물리는 여백이고 도면은 그것에 대해 아무 말도 하지 않는다 |

## 4. 머리글 행 — 4번째 실측이 규칙을 바꿨다

세 문서 다 이력 표의 **맨 아래 행이 머리글**(`REV. DATE DESCRIPTION`)이고,
그 행만 개정 행보다 조금 높다.  띠 안의 간격을 최빈값과 견주어 전수로 세면
(`spike/hist_gaps.py` · 세 문서 전 장):

| 벗어난 정도 | 간격 수 | 무엇 |
| ---: | ---: | --- |
| 0.0% | 626 | 개정 행 |
| 0.1% | 4 | 개정 행 |
| 0.4% | 174 | 개정 행 |
| 1.4% | 85 | 개정 행 |
| — | **0** | **빈 띠 (1.4% ~ 2.8%)** |
| 2.8% | 1 | 머리글 행 (TC2 p37) |
| 3.9% | 2 | 머리글 행 |
| 4.2% | 59 | 머리글 행 |
| 4.3% | 13 | 머리글 행 |
| 4.4% | 4 | 머리글 행 |
| 4.7% | 48 | 머리글 행 |

빈 띠가 있으므로 허용치를 그 사이 어디에 두어도 답이 같다 — **2%** 로 두었다
(16회차 `brk_max_mark` 25.9~28.3 · 17회차 C-4 41.4~190.8 과 같은 근거).

## 5. ★ 표본이 둘인 규칙

`hist_rule_x1_min` 의 근거인 **"노트 열의 안쪽 괘선"** 은 AL NOUF1 과 SADARA
두 문서에서만 확인된다 — TC2 에는 그 괘선이 없어 시트 가장자리로 떨어진다.
즉 이 항목은 **표본 둘로 정한 규칙**이고, 넷째 프로젝트에서 다시 봐야 한다.

**넷째 프로젝트 재확인 목록**

1. 노트 열 안쪽 괘선이 있는가 (`hist_rule_x1_min` 의 근거)
2. 머리글 행이 개정 행보다 높은가 · 몇 %인가 (빈 띠가 유지되는가)
3. 이력 띠가 정말 둘인가 (셋 이상이면 "촘촘한 쪽"이 답이 아닐 수 있다)
4. REV 칸에 개정 삼각형을 그리는가 (그리면 글리프 층의 문제로 넘어간다)
