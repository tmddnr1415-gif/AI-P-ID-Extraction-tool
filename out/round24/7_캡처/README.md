# 캡처 — 무엇을 찍은 것인지

**화면 캡처가 아니라 도면 렌더와 측정 로그다.**  그대로 적는다.

| 파일 | 무엇 |
| --- | --- |
| `tc2_rev칸.png` | TC2 p1 의 타이틀블록 REV 칸.  캡션 `REV.` 아래에 **연한 획 글꼴의 `A`** 가 인쇄돼 있다 — 24회차 전에는 이 글자를 읽고도 이름을 붙일 수 없었다 (글리프 사전이 비어 있었다) |
| `tc2_이력표.png` | TC2 p1 의 개정 이력 표.  맨 아래가 머리글 행(`REV. DATE DESCRIPTION`), 그 위가 개정 행 `A` + `26.08.21` + `FOR INTERNAL USE`.  REV 칸마다 **개정 삼각형**이 그려져 있다 |
| `sadara_이력표.png` | SADARA p1 의 같은 자리.  삼각형 · 머리글 행 · `A` + `19.MAR.2026` |
| `tc2_before_after.txt` | `spike/hist_verify.py` 원문 — 설정값 그대로 **REV 0/60** ↔ 유도값을 얹고 **REV 60/60 'A' HIGH** |
| `alnouf1_before_after.txt` | 같은 도구의 AL NOUF1 원문 — 이력 칸만 유도값으로 바꿔도 글리프 사전 · 이력 행 7 · REV 58/58 이 **한 칸도 안 다르다** |
