## 4. 문장만으로 그 장에서 계기를 가르나 (진단 — 새 축이 아닙니다)

795행 중 **같은 장에 글자 그대로 같은 문장이 또 있는 행 6 (0.8%)** · 3묶음 · 전부 p31.

```
TI    UNIT #10 ACW PUMP TEMPERATURE A     ← 17회차 접미 (of 3)
TIT   UNIT #10 ACW PUMP TEMPERATURE A     ← 도면 근거 순번 (instrument_ordinals)
… B · C 도 같은 모양
```

**★ 두 구분 기전이 겹쳤습니다.**  `instrument_ordinals` 는 *같은 기기의 같은 TYPE* 을
묶어 도면 근거로 A·B·C 를 주고, 17회차 접미는 *지금 글자 그대로 같은 문장* 을 묶습니다.
TIT 3행이 이미 A·B·C 를 달고 있었으므로 접미 쪽은 **TI 3행만** 한 묶음으로 보았고,
그래서 두 TYPE 이 같은 글자를 씁니다.

**행 자체는 TYPE 열로 갈립니다 — 문장만으로는 안 갈립니다.**  고치려면 접미가 순번을
보게 해야 하고 그러면 **AL NOUF1 지문이 움직입니다** → **실무 판단**입니다.
(나머지 789행 99.2% 는 그 장 안에서 문장만으로 유일합니다.)
