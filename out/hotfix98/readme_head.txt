hotfix98 — PID_dev + 운영(PID) 꾸러미  (97a8732 기준 누적 · hotfix56 ~ 97 + LOGIC L1 ~ L27 포함)

LOGIC 검토 (이번에 새로 들어간 것)
  · 대시보드 안에서 '지우기' · '확인' 창이 안 뜨던 것을 고쳤습니다
         (창을 페이지 안에 띄웁니다 — 프로젝트 삭제가 대시보드에서 됩니다).
  · L26: 감시 블록(HHH · HH · LL …)의 설정값은 도면에 적힌 값으로 시작하고,
         신호가 설정값을 넘으면 출력이 1 이 됩니다.  값은 직접 바꿀 수 있고
         바꾼 사람 이름이 남습니다.  MED(중간값) 블록도 계산합니다.
  · L27: 아날로그 입력은 4~20 mA 로 넣습니다 (처음 값 8 mA).
         범위는 도면에 적힌 값을 읽고, 못 읽으면 직접 적습니다.
         경보 설정값(예: HH : 95degC)도 도면 값이 처음 값입니다.
  · 이미 분석한 Logic 은 업데이트 뒤 다시 분석해야 바뀝니다.

이전 꾸러미 내용도 모두 들어 있습니다 (hotfix97: Logic L23 ~ L25 · 프로젝트 삭제 등).
