hotfix92 — PID_dev + 운영(PID) 꾸러미  (97a8732 기준 누적 · hotfix56 ~ 92 + LOGIC L1 ~ L14 포함)

P&ID 분석의 최신 고침과 LOGIC 검토의 최신 작업을 한 꾸러미에 담았습니다.

P&ID 분석
  · (hotfix91) 마크업 사각형을 놓으면 속성 입력 창이 바로 뜹니다.  도면에서 읽은 제안값은 뒤따라
    채워지고, 그 사이 적은 칸은 덮어쓰지 않습니다.  그동안 서버 전체가 멈추던 것도 고쳤습니다.
  · (hotfix92) 여러 사람이 동시에 쓸 때 가끔 엉뚱한 "없음(404)" · 서버 오류(500) 가 나던 원인
    하나를 고쳤습니다 (같은 순간의 두 요청이 서로의 읽기를 섞던 것).
  · 장별 메모를 열 때 메모가 없는 장에서 화면 오류가 나던 것을 고쳤습니다.

LOGIC 검토 (L8 ~ L14)
  · 메모 · 핀 메모 · 전체창 · 게이트 입출력에 1/0 표시 · S-R 래치 동작표
  · 범례(G003)의 모든 게이트를 정의대로 동작 — 입력 조건이 안 맞으면 출력이 서지 않습니다
  · 행 동그라미(입력·출력)에서 1/0 지정 · TO 를 따라 다른 시트로 계속 이어감
  · TO 를 따라 이동하다 만난 설계 오류를 알림 · 매크로 블록(MOV BLOCK 등)을 새 창으로 열어 내부 동작 확인
  · 분석률 · From-To 보고 · 교차선 · 거꾸로 따라가기 · 모순 표시
  · 출력 하나를 고르면 그 출력이 서는 입력 조합을 찾아 보여 주는 '동작 예시'
  · LOGIC 첫 화면: 프로젝트를 고르고 Logic(필수) · Loop · System Description · IO List · Logic Table 을
    넣고 분석 (Logic 외 자료는 지금은 보관만 합니다)
