무엇이 달라지나
  1. 속도: 데이터시트마다 검토 결과를 기억해 두고(메모리 + pid_data/valve/cache/review/) 바뀐 것만 다시 계산합니다.
     서버를 켜면 뒤에서 미리 계산합니다. 화면 전환 · Tag 이동 · PMS/Process 화면이 거의 바로 뜹니다 (1,000 Tag 규모에서도).
     큰 표는 250행을 먼저 그리고 나머지는 쉬는 틈에 그려서 화면이 멈추지 않습니다.
  2. 화면: 같은 이유의 지적(예: Process Data 빈칸 13개)은 한 카드로 묶고 상태를 한 번에 바꿉니다. 오른쪽 탭은 한 줄.
     설명 문장은 머리의 '?' 단추를 켤 때만 보입니다. 대시보드 타일 8개. Settings › 정보와 왼쪽 아래에 버전이 보입니다.
  3. 신뢰: 합성 데이터시트 10,000건을 엔지니어 기준과 프로그램이 서로 검토해 비교했습니다 (예외 0 · 일치 100 %).
     그 과정에서 고친 것: 'R-PTFE' 표기(실자료 41건) · 메탈/나일론 시트 비교 · LCC/LF2 = 저온 탄소강 · XC0K8 처럼 2점짜리 P-T 표 ·
     HOLD 인 Fire Safe 는 재질 의견 제외 · Fire Safe 빈칸인데 PMS 품목이 Fire tested 인 18건을 새로 찾음.
  4. 매일 처음 켤 때 valve.db 를 pid_data/valve/backups/ 에 복사합니다 (7개 보관).
