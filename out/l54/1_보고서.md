# L54 — LOGIC 작도: 분석한 로직과 같은 양식으로 그린다 (2026-10-25)

지시: *저 로직을 캐드 환경에서 동일한 포맷으로 그릴 수 있는 툴을 만들고 싶다 — LOGIC 분석 밑 하위 메뉴로.*

## 어디서 여나

* 왼쪽 메뉴 **LOGIC 검토 → LOGIC 작도** (하위 메뉴) · LOGIC 검토 화면 머리줄의 **✎ 작도** 단추 · 주소 `/logic/draw`.

## 확인한 것

* 기호 열네 가지(글 주석 빼고)를 한 장에 놓고 행과 이어 PDF 로 내보낸 뒤 분석기에 넣으니 **전부 같은 종류 · 같은 입출력 · 같은 행 글 · 같은 시트 이름**으로 읽혔다 (시간 3·4·2초 · 투표 2/3 · SET 우선 메모리 · 누름단추 이름까지).
* 화면을 띄워 눌러 보았다 — 새 그림 → 기호 셋 → 선 여섯 → 표 칸 아홉 → 저장 → 되읽기 검증 "전부 같게 읽혔습니다" → PDF · DXF 내려받기 → 검토로 보내기(1장 분석 완료) → 그 시트를 다시 가져오기.  화면 오류 0.
* 이미 분석한 네 묶음(HRSG · 1A5J · 1A1Y · 19VA)은 선 · 블록 구조가 바뀌지 않았다.

## 분석기에서 같이 고친 둘 (작도한 PDF 를 되읽다 드러난 것)

1. **연결 기호의 글자** — 글자를 진짜 글자로 인쇄한 양식에서 원 안의 `A` 가 범례 사전의 아날로그 신호 발생기(`A`)로 읽혔다.  꼭지 삼각형이 붙은 원은 모양으로 이미 연결 기호이므로 범례 사전에 맞대지 않고, 원 안 글자를 그 연결 기호의 글자로 읽는다.
2. **타이머의 시간** — 타이머 두 개가 두 행 간격으로 쌓이면 **아래 타이머가 위 타이머의 초**를 가져갔다 (1A5J 0016 의 OFF DELAY `2SEC` 가 위 ON `5SEC` 로 · 19VA 아홉 곳도 같은 꼴).  이제 블록에 가장 가까운 글줄의 초를 쓴다.  열 곳 전부 그림으로 확인했다.

## 못 한 것 · 다음

* 매크로 상자(단자 이름이 붙은 큰 상자)는 아직 팔레트에 없다 — 그린 뒤 분석기가 Typical 시트와 잇는 길까지 맞추려면 Typical 시트 그리기가 먼저다.
* 제목은 문서 번호(숫자-숫자 꼴)가 있어야 분석기가 읽는다 (19VA 양식의 규칙) — 문서 번호를 비우면 가져올 때 제목이 비거나 엉뚱하다.
* 여러 장짜리 묶음(시트 사이 FM/TO)은 그림마다 한 장씩 그려 각각 PDF 로 내보낸다 — 묶음으로 한 PDF 에 합치는 단추는 다음 후보.
