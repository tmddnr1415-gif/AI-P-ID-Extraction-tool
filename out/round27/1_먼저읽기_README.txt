━━ ★ r27 에서 무엇이 고쳐졌나 — 수량입니다
--------------------------------------------------------------------------------
알려 주신 대로, 도면의 NOTE 가 "이 P&ID 는 유닛 몇 개에 같이 쓰인다" 고 말하면
그 수를 수량에 씁니다.

    THIS P&ID IS FOR UNIT 3-1.  AND, SIMILAR SCHEME IS APPLICABLE TO
    UNIT 3-2, UNIT 4-1, … UNIT 6-2.          -> 유닛 8개  -> Q'ty x8

`SIMILAR` · `IDENTICAL` · `SAME` · `TYPICAL` 을 **전부 같은 뜻**으로 읽습니다.
문장 모양을 외우지 않고 **그 문단이 열거한 유닛 표기를 셉니다** — 그래서
아래 여섯 문형이 전부 됩니다 (실측):

    THIS P&ID IS FOR GROUP #10, CONFIGURATION IS IDENTICAL FOR GROUP #20.   (2)
    THIS P&ID IS FOR UNIT#11, … IDENTICAL FOR UNIT#12,21,22.               (4)
    THIS P&ID IS FOR UNIT 3-1. AND, SIMILAR … TO UNIT 3-2, … 6-2.          (8)
    THE P & ID IS TYPICAL FOR UNIT 3-1 & 3-2, SIMILAR … FOR 4-1 & 4-2, …   (8)
    THIS P&ID IS COMMON FOR UNITS NO.3-1 & 3-2. AN IDENTICAL SYSTEM …      (8)
    THIS P&ID IS APPLICABLE FOR UNIT 3-1 AND IS TYPICAL FOR UNITS 3-2, …   (8)

큰 도면(60장) 실측:

    r26   Q'ty 합계   345  ·  수량이 빈 행 262  ·  나머지는 다른 프로젝트 설정값
    r27   Q'ty 합계  3047  ·  수량이 빈 행   0
          내역 — x8 308행 · x4 94행 · x2 2행 · x1 203행(노트가 없는 장)

보내 주신 9쪽(UNIT 3-1 … 6-2)은 이제 **x8** 로 나옵니다.


━━ 읽는 순서 — 도면이 먼저, 설정은 마지막
--------------------------------------------------------------------------------
    1. 그 문서의 범례 UNIT IDENTIFICATION NUMBERS 표   <- 있으면 여기서 끝
    2. 그 장의 NOTES ("… IDENTICAL / SIMILAR / TYPICAL … UNIT 3-2, …")
    3. 프로젝트 설정값 (= 다른 도면에서 잰 값 · 행이 검토 사유로 그렇게 말합니다)
    4. 아무 것도 없으면 빈칸 + 사유

노트가 설정값보다 셉니다 (설정값은 그 도면이 한 말이 아니므로).
범례 표보다는 약합니다 (이미 답이 있는 문서의 판정을 흔들지 않으려고).

★ 그래서 **AL NOUF1 은 한 칸도 달라지지 않습니다** — 그 문서는 범례에
UNIT IDENTIFICATION NUMBERS 표가 있어 1번에서 끝납니다.


━━ 다른 프로젝트의 P&ID 가 와도 그때마다 읽습니다
--------------------------------------------------------------------------------
· NOTES 가 도면 어디에 인쇄돼 있는지는 **그 도면에서 찾습니다** (코드에 좌표 없음).
· 낱말만 설정 파일에 있습니다 — config\project_alnouf1.yaml 의 `qty_note`:

      qty_note:
        same_words:  [IDENTICAL, SIMILAR, SAME, TYPICAL]
        unit_words:  [GROUP, UNIT, TRAIN]
        range_words: [THRU, THROUGH, '~']

  새 프로젝트가 유닛을 `BLOCK` 이나 `PHASE` 로 부르면 **프로그램을 고치지 않고
  여기 한 줄** 더하면 됩니다.

· 범위로 적힌 노트(`UNIT 3-1 THRU 6-2`)는 **세지 않습니다.**  도면이 인쇄한 것은
  두 끝뿐이고 사이에 무엇이 있는지 말하지 않기 때문입니다 — 두 끝을 세면 2가 되어
  틀린 수가 맞는 얼굴을 합니다.  그런 장은 수량을 비우고 검토 사유로 올립니다.
  (지금 세 문서에는 이런 노트가 없습니다.)
