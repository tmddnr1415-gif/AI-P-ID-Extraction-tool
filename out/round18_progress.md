## [E] 조사 결과 — 원인은 `actuator NONE` 이 아니었다

**17회차 [B] 게이트는 잘못된 원인을 재고 있었다.**  네 안 모두
`actuator NONE` 정책을 완화하는 것이었는데, 지목된 건들의 실제 원인은
**몸체 기하**다.

원인 사슬 (p10 XV 실측):
```
1. 범례 p2 가 ANGLE 을 정의한다 — 직각으로 꼭짓점을 맞댄 두 중공 삼각형
2. 검출기의 몸체 어휘에 ANGLE 이 없다 (GATE·GLOBE·BUTTERFLY·BALL·CHECK·DIAPHRAGM)
   → 왼쪽 삼각형 하나만 `CHECK` 로 읽는다  rect=(719.0,807.6,728.8,812.8)
   → 진짜 도형은 (718.7,797.5,733.4,812.8) · 6선분 · 14.7x15.3
3. 그 rect 의 중심 x=723.9 가 **진짜 스템축 x=728.7 에서 4.86pt** 어긋난다
4. 공압 실린더는 **제대로 찾고 있다** — (721.7,827.4,735.8,841.5)
   `PNEUMATIC CYLINDER DOUBLE-ACTING` (범례 p3)
5. 그런데 `act_offaxis = 0.83pt` 가 off=4.86 을 거부한다 (stem 검사는 통과)
6. actuator=NONE → deliverable_class 첫 줄 → EXCLUDED
```

**꼭짓점에서 재면 off = 0.15pt 다** (실린더 중심 728.75 ↔ 꼭짓점 728.6).
즉 허용치를 늘릴 일이 아니라 **재는 점이 틀린 것**이다 — 16회차 벤더 별표
때와 같다("허용치는 건드리지 않고 읽는 사각형만 바꿨다").

**★ p20 미상 심볼도 ANGLE 이다** — 범례 p2 ANGLE + 범례 p3 `PNEUMATIC
DIAPHRAGM WITH POSITIONER`(I/P 상자 + 돔) + `VS` + `NOTE3`.

아니다.**  세 회차 동안 "미지정"이던 것이 범례에 있었다.
