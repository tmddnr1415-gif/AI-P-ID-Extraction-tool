# [C] 경보 접미 — **측정만 했다.  코드 0줄.**

30회차 [C]가 남긴 것: UAD 미검출 36건 중 **21건**이 `LSA++` · `LS++,+,-,--`
처럼 수식자가 글자에 붙어 인쇄돼, 앵커가 **낱말 통째 일치**라 후보에도 못
들었다.  로드맵 2순위이고, **AL NOUF1 에 행이 늘 위험**이 게이트다.

---

## 1. UAD p4 ISA 문자표가 수식자를 **정의한다** (§9 ①)

추측이 아니다.  그 장이 인쇄한 원문 그대로:

```
SUCCEEDING LETTERS            (표 머리)
   LOW          HIGH          HIGH & LOW
ALARM SET POINT
   +,++,-,-                   ← 표기
   +  : HIGH
   ++ : HIGH HIGH
   -  : LOW
   -- : LOW LOW
```

즉 **`+`·`-` 의 되풀이가 경보 설정점이라는 것을 그 도면이 말한다.**
어휘를 지어낼 필요가 없다 — 읽을 곳이 있다.

## 2. 네 문서에서 "접미가 붙은 앵커 낱말" 을 셌다

두 갈래로 나눠 센다.

```
(a) 수식자만 떼면 앵커가 된다      `LS++,+,-,--` → `LS`
(b) 뒤 A(Alarm)까지 떼야 앵커      `LSA++` → `LSA` → `LS`
```

| 프로젝트 | (a) 낱말종/횟수 | (b) 낱말종/횟수 | 무엇인가 |
| --- | --- | --- | --- |
| **AL NOUF1** | **1종 / 2회** | **0 / 0** | `XV->` (p17) |
| SADARA | 1종 / 1회 | 0 / 0 | `TIT.` (문장 끝 마침표) |
| TC2 | 1종 / 1회 | 0 / 0 | `PIT.` (문장 끝 마침표) |
| **UAD** | **1종 / 21회** | **10종 / 59회** | `LS++,+,-,--` / `LSA++` · `TIA+,-` · `PIA+,-` … |

**(a) 의 21회는 30회차가 센 미검출 `CL101` 21건과 정확히 같은 수다.**
장도 같다 (p29 5 · p30 12 · p31 4).

## 3. ★ AL NOUF1 의 위험 2건은 **계기가 아니라 사람이 쓴 메모다**

`XV->` 두 건을 렌더로 열었다 (`7_캡처/AL_NOUF1_p17_XV_리뷰메모.png`).

> **노란 바탕 · 빨간 테두리 상자에 `XV-> CV` 라고 적고 빨간 화살표로 왼쪽
> 버블을 가리킨다.**  검토자가 *"이 XV 를 CV 로 고쳐라"* 라고 쓴 것이다.

엔진은 그 장을 이미 알고 있다 — p17 의 행 15개 중 **10개**에
`annotation: "reviewer markup on this drawing"` 이 붙어 있다.

**★ 그래서 이것은 위험의 크기가 아니라 새 위험의 이름이다** —
접미를 떼는 규칙을 넣으면 **사람이 쓴 검토 메모가 계기로 읽힐 수 있다.**
UAD 에서 SHX 주석을 들여올 때 28회차가 이미 같은 함정을 만나 *제목이 정확히
`AutoCAD SHX Text` 인 것만* 받았다.  같은 규율이 여기에도 필요하다.

## 5. §5.1 LS 판정과 충돌하는가 — **(b) 는 충돌하고 (a) 는 안 한다**

`CLAUDE.md` §5-1 / 9회차가 정한 것: *한 물리 계기가 내는 여러 신호 버블은
한 행으로 접는다* (AL NOUF1 34묶음 102버블 → 34행).

UAD p30 실측 — 태그 `00GMA01CL101` **하나에 버블이 셋**이다:

```
LSA++            00GMA01CL101      (네모 테두리 = 원격/DCS)
LSA++,+,-,--     00GMA01CL101      LCP
LS++,+,-,--      00GMA01CL101      ← 현장 스위치
```

* 규칙 **(a)** 만 쓰면 현장 스위치 하나만 잡혀 **태그당 1행** — §5.1 과 맞는다.
* 규칙 **(b)** 까지 쓰면 `LSA` 둘이 더 잡혀 **태그당 3행** — §5.1 을 정면으로
  어긴다 (경보명을 계기로 승격시키는 것).

**그러므로 (b) 는 채택 대상이 아니다.**  (b) 로 잡히는 59회 중 UAD 의
`TIA`·`PIA` 15회도 같은 성격이다 — p8 렌더에서 `PIA+,-` 는 `PIT` **위에**
따로 그려진 경보 버블이다.
