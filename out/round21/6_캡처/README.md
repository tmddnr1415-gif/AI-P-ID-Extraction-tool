## 무엇이 달라졌나

| | before (r20) | after |
|---|---|---|
| 사유 | `이 PDF 를 분석하지 못했습니다. 사유를 특정하지 못했습니다.` | 어느 칸을 어디로 보고 있었는지 · 이 문서의 쪽 크기 · **그 칸을 재는 데 성공했는지** · 무엇을 하면 되는지 |
| 어디서 멈췄나 | `도면을 한 장도 읽기 전에 멈췄습니다` (여섯 단계를 한 문장이 덮음) | `도면을 읽기 전, 타이틀블록을 읽는 중 단계에서 멈췄습니다` |
| 예외 원문 | 화면에 없음 (진단 zip 을 풀어야 함) | **접힌 채로 있고 펼치면 받아 옵니다** |
| 멈추는 시점 | 준비 작업을 다 지난 뒤 | **그대로** — 당기지 못했습니다 (`5_원인과대책.md` §2) |

두 갈래가 서로 다른 문장을 냅니다:

- `other_form` (A3) → `20장 전부에서 종이 밖입니다 (… 1191.0x842.0pt 20장)`
- `thin_history` (A1) → `종이 안이지만 비어 있습니다 (… 2384.0x1684.0pt 12장)`

둘 다 뒤에 `이 도면에서 그 칸을 재지 못해 프로젝트 설정 title_block 의 값을
그대로 썼습니다` 가 붙습니다 — 그 판정은 `_fit_layout` 의 `moved` 가 답합니다.
