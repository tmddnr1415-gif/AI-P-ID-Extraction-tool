승수(Q'ty)를 도면 위 x N 라벨에서 고치기
  1) 계기 표기 오른쪽의 x N 라벨을 누르면 작은 판이 뜹니다
       [이 태그만]  [이 페이지 전체 (N행)]  [취소]
     숫자를 넣고 고르면 됩니다 (Enter = 이 태그만 · Esc = 취소 · 비우면 도면 값으로 되돌림)
  2) Shift 를 누른 채 도면 위를 끌어 범위를 묶은 뒤, 묶인 항목의 x N 라벨을 누르면
       [선택 N개에 적용]
     오른쪽 '선택 N개' 판에도 같은 승수 칸이 있습니다
  3) 바꾼 승수는 왼쪽 도면 라벨(x N ✎)과 오른쪽 목록 Q'ty 칸(✎)에 같이 반영됩니다
     작성자는 한 번만 묻고, 편집 이력에 누가·언제가 남습니다
  4) 큰 상자에 가려 눌리지 않던 x N 라벨을 상자 위로 올렸습니다

확인(회사 Claude): 빠른 시험 · 8001 미리보기에서 결과를 열고 x N 라벨 → 이 태그만 / 이 페이지 전체 /
Shift 범위를 각각 한 번씩.  엔진(판정) 코드는 바뀌지 않았습니다 — 다시 분석할 필요 없습니다.
