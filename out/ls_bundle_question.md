# 다중 신호 버블 — 물리 수량 확인 요청

도면에서 세로로 **맞닿아** 그려진 계기 버블 묶음이 있습니다. 물리적으로 하나의 기기에서 나오는 여러 신호로 보이지만, **도구는 수량을 합산하지 않았습니다** — 아래 두 근거가 서로 다른 도면을 말하고 있어 이 도구가 판단할 수 없습니다.

## 무엇을 물어보는지

- 묶음 **34건**, 버블 **102개**, 현재 리스트에 **102행** · Q'ty 합계 **102**
- 합산한다면 행이 102 → **34행** 이 됩니다 (수량 합계는 승수에 따라 재계산)
- 현재 상태: 전 행 리스트 유지 + `다중 신호 버블 — 물리 수량 확인 필요` 로 검토 대기

## 도면이 말하는 것 (측정)

- `LSHH + LSH + LSL` 구성 묶음 34건
- 버블 사이 세로 간격: **0.0, 0.06pt** (허용치 0.8pt, `legend_rules.INDEX_SLACK`). 이 문서에서 가로로 겹치는 다른 버블 쌍의 최소 간격은 3pt 이고, 맞닿은 것은 이 묶음뿐입니다
- 묶음마다 리드선이 **1개**이고, 그 리드선은 묶음의 버블 중 **1개**에만 닿습니다

## 문서가 답하지 않는 것

- 범례 p3 `INSTRUMENT FOR SINGLE MEASURED VARIABLE AND ANY NUMBER OF FUNCTIONS` 는 다기능 계기를 **버블 1개**로 그립니다. 범례에는 맞닿은 묶음 표기가 **없습니다**
- 발주처 계기 리스트는 LS 22행 = 도면 버블 22개로 **버블 1개당 1행**을 쓰지만, 그 22행이 있는 도면에는 이 묶음이 **없습니다**. 묶음이 있는 도면 5장은 리스트가 다루지 않습니다
