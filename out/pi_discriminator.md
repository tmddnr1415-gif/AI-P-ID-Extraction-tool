## 1. 먼저 확인된 구조 — 갈림은 버블이 아니라 도면 단위입니다

PI 가 있는 교집합 도면 17장:

| | 도면 |
| --- | ---: |
| 발주처 수 == 우리 수 (그 도면의 PI 를 전부 셈) | **9장** |
| 발주처 수 == 0 (그 도면의 PI 를 전혀 안 셈) | **8장** |
| 부분적으로 셈 | **0장** |

한 도면 안에서 어떤 PI 는 세고 어떤 PI 는 안 세는 도면이 **하나도 없습니다.**
그리고 세는 9장에서는 우리 수와 발주처 수가 **정확히 일치**합니다
(21·21·20·16·14·8·4·3·2 = 109 = 발주처 109).

이것이 이 회차의 가장 중요한 사실입니다.  **버블에서 재는 어떤 값도, 이 갈림을
재현하려면 그 값이 도면 안에서 균일해야 합니다.**  계장 신호선은 버블마다
다를 수 있는 값이므로, 가설은 시작부터 불리한 위치에 있었습니다.

같은 성질이 다른 TYPE 에도 있습니다 — 통째로 빠지는 TYPE 은 PI(8장) ·
RO(3장) · LI(3장) 뿐이고, PIT 는 27장 중 통째로 빠진 도면이 **0장**입니다.

### 3-1. 벤더 별표 — 유일하게 방향이 맞는 축

먼저 도면이 말로 하고 있습니다.  PI 를 안 세는 8장 중 **8장 모두** NOTES 에
벤더 공급 문구가 있고, 그중 세 장은 문자 그대로 계기를 지목합니다:

```
00PAB10-M05-0001/2/3 : AUTOMATIC AIR RELEASE VALVE AND PRESSURE GAUGE
                       WILL BE SUPPLIED BY CWP SUPPLIER.
00GHC10-M05-0001     : * TO BE SUPPLIED BY PUMP VENDOR.
00GKB10-M05-0001     : 1. MARKED WITH * TO BE SUPPLIED BY PUMP VENDOR.
00GHB10-M05-0001     : 1. PUMP VENDOR SHALL PROVIDE THE INSTRUMENT.
```

PI 를 세는 9장 중 마크 사전을 가진 것은 **1장**뿐이고, 그 뜻은
`EQUIPMENT PROVIDED BY PUMP VENDOR` — 기기이지 계기가 아닙니다.

| PIT | 98 | 0.0% | 1.0% | 4.1% |
| TIT | 97 | 1.0% | 1.0% | 5.2% |
| TI | 58 | 0.0% | 0.0% | 0.0% |

마크가 붙는 TYPE 은 정확히 **PI · RO · LI** — 통째로 빠지는 세 TYPE 과 같습니다.

### 3-2. 그런데 회수율이 30% 입니다

'버블 짧은 변의 0.5배 안에 벤더 마크가 있으면 계상하지 않는다' 를 전 TYPE 에
적용하면:

정밀도 92.1%, 회수율 30.4%.  오탐 3건은 `00EGD00-M05-0002` LI 2건과
`10PGB10-M05-0001` TIT 1건입니다.

## 4. 채택하지 않은 것과 그 이유

**"유닛코드 00 도면에서는 PI·RO 를 세지 않는다"** — 이 문서에서는 PI 7/7,
RO 3/3 으로 맞습니다.  그러나 이것은 **AL NOUF1 의 도면번호 체계를 관찰한
것**이지 도면이나 범례에서 유도한 것이 아닙니다.  §[C] 의 분류상 **프로젝트
종속**이며, 금지 사항("AL NOUF1 관찰에서 유도한 규칙을 범용 규칙이라 부르는
것")에 정면으로 해당합니다.  기록만 하고 채택하지 않습니다.
(반례도 이미 있습니다 — `10PGB10-M05-0001` 은 유닛코드 10 인데 PI 4건이
빠집니다.)

**벤더 별표** — 이것은 범례·NOTES 에서 유도되므로 **원리상 범용 후보**입니다.
그러나 회수율 30% 이고, SADARA 정답지가 없어 다른 문서에서 검증할 수 없습니다.
**후보 상태로만 남깁니다.**

## 5. 90% 목표에 대해

PI 48 을 벤더 마크로 제외하면 21건이 빠집니다:

```
현재      595 / 708 = 84.0%
마크 적용  595 / 687 = 86.6%
PI 전량    595 / 660 = 90.2%   <- 판별자가 없으므로 하지 않습니다
```

**판별자 없이 PI 를 제외하는 것은 이번 회차의 금지 사항입니다.**  90% 는 이
경로로 닿지 않습니다.
