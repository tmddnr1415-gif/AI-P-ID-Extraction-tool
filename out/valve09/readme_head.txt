valve09 — HOLD / TBC 를 전부 지적 (+ valve08 까지 전부)

무엇이 달라지나
  1. 데이터시트의 모든 칸과 Note 에서 HOLD · TBC · TBA 를 찾아 'Open Item'(주황 · Major)으로 PDF 위에 표시하고
     Issue List Excel · Mark-up PDF 에 넣습니다. 설명: "… is 'HOLD' — on HOLD / TBC: release the HOLD and give the value".
  2. 값 중간에 있어도 잡습니다: 'HOLD (in accordance with API 607/ API 6FA)', 'Note-9, Hold-1'(HOLD 목록 1번 글을 함께 적음),
     Note 'Partial Stroke Test: TBC …', 'HOLD:' 목록 항목.
  3. 'VTA - Vendor to Advise, TBC - To be Confirmed …' 같은 약어 설명 줄은 지적하지 않습니다.
  4. 실자료(456쪽) 84건 — 전에는 0건이었습니다.

적용 순서
  1) apply_to_PID_dev.bat → 확인 → 2) apply_to_PID_ops.bat → 8000 서버 재시작
  valve01~08 을 적용하지 않았어도 이것 하나로 됩니다. 대시보드는 바꿀 것 없음.
