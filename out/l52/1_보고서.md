## 찾아 고친 것 셋

1. **CAD 가 신호선과 AND 상자 테두리를 한 path 로 내보낸 장** (HRSG G043 · G030 · G035 · G040 · G042 · G044) — 테두리가 선으로 남아
   입력과 출력이 한 선이 되었다.  G043 의 STOP 명령 둘이 영영 0 이었고 G040 은 STEP 사이 AND 가 건너뛰어졌다.
2. **되먹임 고리로만 서로를 모는 선** (OR 자기유지) — 처음 값이 없어 모름이었다.  전원이 들어온 순간 0 에서 시작하고 호출 사이에 값을 잇는다.
3. **예시 찾기가 다른 장에서 오는 행을 0 으로 못 두었다** (19VA `… BYP MOV OP REQ`).

## 확인 대상 (도면)

* 1A5J 0017 · 0019 `STARTUP CRITICAL PROCESS ON` / `CHANGE LOAD ON` = GROUP START 펄스 AND (모든 드라이브 5초 유지) — 펄스가 5초보다 길어야 선다.
