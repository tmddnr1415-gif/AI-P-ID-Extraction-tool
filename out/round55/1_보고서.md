## C · 범례 블록 사전 (`round55_legend_blocks.md`) — 코드에 이름 0

- 뜻은 **구획 머리말**(그 장에서 세 번 이상 인쇄된 가장 큰 글자 5.0 — `EQUIPMENT` · `LINE VALVES` ·
  `VALVES ACTUATORS` · `GENERAL INSTRUMENTS` · `SENSOR-*` …)과 **옆 캡션**(심볼 중심을 품는 줄의 오른쪽
  글자)이 정한다.  결과 계기 12 · 밸브 15(`GATE` · `GLOBE`→`SMALL`⚠ · `BALL` · `BUTTERFLY` · `CHECK` …) ·
  액추에이터 9(`MOTOR` · `HYDRAULIC` · `SOLENOID` · `PNEUMATIC` · 손 `NONE`) · 기기 34.
- **계기 여부의 1급 근거는 블록 정의의 속성 쌍**이다 — 범례 p4 의 `INST_*` 블록이 ATTDEF 둘(TYPE · 태그)을
  선언한다.  어느 이름이 TYPE 이고 태그인지는 **값이 정한다**: TYPE = 값의 절반 이상이 ISA 표로 풀리고
  **같은 블록에 태그 역할 속성이 짝으로 있는** 이름 · 태그 = 절반 이상이 코드 모양이고 두 장 이상에서
  되풀이되는 모양(29회차 규칙).  ⚠ 짝 조건이 없으면 스코프 경계선의 `SCT`·`AG`·`UG` 가 계기가 된다(실측).
- **두 체계가 아니라 셋이다.**  ② `AS_INST` 체계(p16~18)의 계기 블록은 **범례에 없다** → 범례 계기 원과
  같은 반지름(±25%)의 원/호를 그린 블록으로 2급, 사유 `DXF_BLOCK_NOT_IN_LEGEND`.  이름이 아니라 기하.
- **ISA 표** — `isa_table.derive` 를 shim 쪽으로 그대로 불렀다: first 25.  succeeding 은 0 이었다 —
  **50회차가 남긴 그 값**이고 원인은 조각이 아니라 **표의 판**이다: UAD 범례는 `TYPICAL SYMBOL` 머리줄 대신
  `( ) AL` · `( ) K` 칸 한 줄을 찍는다.  그 판을 읽는 규칙을 **DXF 쪽에** 두었다 (PDF 경로 불변 게이트).
  → 대기: `isa_table.derive` 로 옮긴다 (PDF 의 UAD 도 같은 표).

## D · 판정 (`app/dxf_pipeline.py`) · 20종 (`round55_census20.md`)

- 읽는 재료만 바뀌고 판정 함수는 PDF 것을 **부른다** — `_scope_of` · `_supplier_name` · `type_display`

- 걸러낸 층은 **레이어 표의 off · frozen · plot=0** 이다 (`REV.4/5/6` off · `HIDE` frozen ·
