# [E] 기능별 DXF 지원 표 (55회차)

"PDF 에서 되던 것이 DXF 에서도 되는가" — 되는 것은 **같은 코드**가 돌기 때문이고(결과가
같은 모양이라 화면·저장·Excel 이 입력 종류를 모른다), 안 되는 것은 **도면을 다시 여는
함수가 PDF 전용**이기 때문이다.  안 되는 것은 사유와 함께 적는다.

| 기능 (회차) | DXF | 근거 · 사유 |
| --- | --- | --- |
| 업로드 — PDF/DXF 선택 · zip 하나 · .dxf 여러 장 | ✔ | `create_job` 이 파일 머리로 가른다 (`%PDF-` · `PK` · `.dxf`).  여러 장은 zip 하나로 묶어 저장 |
| 분석 · 진행률 · 장수 | ✔ | `pipeline.analyse` 갈림 한 줄 → `dxf_pipeline.analyse` (32장 60초).  `_count_pages` 는 DXF 장 수 |
| 결과 그리드 · 검토 사유 · 근거 패널 | ✔ | 행 모양이 같다 (`Row` 그대로 · `evidence.review_codes`) |
| 오버레이 · 범례 카운팅 (33회차 등식) | ✔ | `layers` 를 같은 모양으로 낸다 · 배경은 `dxf_render` PNG (픽셀 = 모델 × 3) · 32장 캡처에서 칸 합 = 상자 수 확인 |
| 편집값 층 (14) · 수정 이력 | ✔ | `store_result` · `PATCH /rows` 가 입력 종류를 모른다 |
| 프로젝트 영속 (13) · 개정 비교 · 안정 ID (§7.3) | ✔ · ⚠ | 같은 장부.  ⚠ **같은 프로젝트에 PDF 와 DXF 를 섞지 않는다** — 첫 입력 종류와 다르면 400.  개정 비교는 DXF↔DXF 만 |
| 마크업 — 사각형 추가 (44) | ✔(반쪽) | 사각형·행 추가·녹색 표기는 된다.  **제안값은 없다** — `markup.propose` 가 DXF 면 빈 제안(USER) 을 돌려준다 (`propose_at` 이 PDF 전용).  다음 회차 |
| 마크업 좌표 | ✔ | 표시 좌표(y 아래 · 모델 단위)로 저장 · `job.input_kind` 가 종류를 함께 적는다 |
| 오검출 표시 · 되돌리기 (44) | ✔ | 행 단위 |
| 피드백 내보내기 (44) | ✔ | DB 만 읽는다 |
| 프로젝트 삭제 (46) | ✔ | DB·폴더만 |
| 승수 지정 (31) | ✔ | `_note_factor` 순서 그대로 — DXF 는 범례 승수표가 없어 `MULTIPLIER_FROM_CONFIG`(설정 폴백) · 사람 지정이 이긴다 |
| 심볼 등록 (18) | ✔ | `unjudged_symbols` 를 같은 모양으로 낸다 — 범례 밖 블록 · ISA 로 안 풀리는 속성 |
| 발주처 Excel (18) | ✔ | 행 모양이 같다 (SCOPE·Q'ty·TYPE) |
| 입찰/실행 (38) | ✔ | `_attach_tags` 가 `declared_mode` 를 같은 규칙으로 본다 |
| 도면번호 사람 지정 (45) | ✔ | `sheet_numbers` 를 같은 자리에서 받는다 (도면이 이긴다) |
| Description (5~9회차 판정축) | ✘ | **이 회차에 만들지 않았다** — 행마다 `description_needed=False` · 사유 "DXF 경로 — Description 은 이 회차에 만들지 않았다".  배관·기기 라벨·커넥터 읽기가 전부 PDF 낱말·선분 캐시를 전제한다 |
| Typical 참조 (38) · 신호 버블 묶음 (39) · 파선 버블 (40) | ✘ | PDF 기하 함수.  DXF 에는 블록 참조 개수로 같은 뜻을 낼 수 있다 — 다음 회차 |
| 별표 SCOPE (§10-7) | ✔ | 별표 TEXT + 그 장 NOTES `* BY …` 정의줄 → `_scope_of` (같은 함수) |
| 스코프 경계선 블록 (좌/우 속성) | 사실만 | `result.dxf.scope_breaks` 에 값(`SCT/SUPPLIER` · `AG/UG`)을 남기고 판정에 쓰지 않는다 — 실무 판단 |
| 행추가 지점 기하 채집 (`probe_point`) | ✘ | DXF 면 `{"input_kind":"DXF"}` 만 적는다 |

## 렌더 좌표 확인 (렌더로 눈으로)

`dxf_render.render_png` 는 장 범위(프레임 블록 = 종이 841×594)를 정확히 덮는 그림을 픽셀 = 모델 × 3 으로
그린다 (2523×1782).  화면은 이미지 폭 ↔ `page.width` 의 비로 사각형을 놓는다 (`sheetPoint` 그대로).  32장
오버레이 캡처(`out/round55_uad_dxf/p*_overlay.png`)에서 상자가 심볼 위에 놓이는 것을 눈으로 확인했다 —
p11 (1급) · p16 (2급) · p26 (기하) 셋을 대표로 본문에 붙인다.
