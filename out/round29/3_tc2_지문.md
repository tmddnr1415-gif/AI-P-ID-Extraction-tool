### 왜 표본이 하나 줄었나 — TC2 p10 한 줄

`_connector_labels` 는 낱말을 **y 를 5pt 로 나눈 버킷**으로 묶고 **그 줄 전체**가
`^TO …` / `^FROM …` 에 맞는지 본다.  p10 의 y버킷 116 은:

```
옛(텍스트만)   'TO CONDENSER'                 ← 맞음
새(+SHX 주석)  'M TO CONDENSER'               ← 안 맞음
                x=171.0  'M'        ← SHX 주석 (모터 심볼의 글자)
                x=881.6  'TO'
                x=887.9  'CONDENSER'
```

**710pt 떨어진 `M` 한 글자가 같은 5pt 띠에 들어와 문장 앞에 붙었다.**
그래서 커넥터 표본이 181 → 180 이 되고 p90 이 32.3 → 32.5 로 옮겨졌다.
