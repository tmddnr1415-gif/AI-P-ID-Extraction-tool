━━ hotfix32 — 식별 표기 옆에 수량 x N · 도면 위에서 수량을 고치면 목록에 ✎ 와 함께 반영
   hotfix1~31 을 전부 포함합니다.  (hotfix31 의 내용은 아래에 그대로 있습니다)
   화면만 바뀌었습니다 — 다시 분석하지 않아도 되고, 브라우저를 새로 고치면 됩니다.

━━ 요구
   "각 식별된 계기, 식별 표기 옆에 x1, x2 와 같이 note 에 따른, 즉 출력된 수량을 표기하고, 사용자가 수량을
    변경하면 그 변경된 수량이 list 에도 변경 표기와 함께 반영될 수 있도록."

━━ 이제는
   · 식별된 상자마다 오른쪽에 `x2` 같은 수량 라벨이 붙습니다.  값은 목록의 Q'ty 칸과 **같은 값**(NOTES 승수
     반영)이고, 마우스를 올리면 근거(`1 symbol x 2 (NOTES: …)`)가 뜹니다.
   · 라벨을 **누르면 그 자리에 입력 상자**가 뜹니다.  숫자를 넣고 Enter(Esc 취소 · 비우면 도면 값으로) →
     작성자 확인 → 저장.  저장은 목록 칸을 고칠 때와 **같은 길**이라, 목록의 Q'ty 칸이 그 값으로 바뀌고
     녹색 ✎ 가 붙고, 도면 라벨도 녹색 `x5 ✎` 가 되며, 근거 패널에 "사람이 고침 (도면 근거는 2)" 가 적힙니다.
   · 범례에 `수량 x N (그중)` 칸이 생겼습니다 — 끄면 라벨이 숨습니다 (상자 수는 그대로).
   · Excel: 최종 저장 → Excel 출력 을 하면 고친 값이 그대로 나갑니다 (hotfix24 와 같은 길).
