# hotfix49 — 대시보드형 화면 (왼쪽 메뉴 · 지표 카드 · 그래프)

요구: 사내 주간업무 Dashboard 사진 두 장을 보이며 *"UI 를 이런 식으로 바꿔줘."*

사진에서 읽은 것: 남색 왼쪽 메뉴(항목 · 건수 배지 · 노란 NEW 알약 · 아래 사용자/서버 상태) · 밝은 본문 ·
파란 제목 + 회색 부제 · 오른쪽 위 파란 주 버튼과 흰 보조 버튼 · 붉은 알림 알약 · 큰 숫자 카드와
`바로가기 →` · 세로 막대 · 가로 막대 · 도넛 그래프 · 노란 메모 카드 · 최근 이력 카드.

**엔진·서버 0줄.**  바뀐 파일은 `app/static/index.html` · `styles.css` · `app.js` 셋과 시험 · 도구뿐이고
판정·지문·저장에 닿을 길이 없다.  그래서 네 프로젝트 회귀는 돌리지 않았다.

## 2. 지표와 그래프는 새로 세지 않는다

전부 서버가 이미 내던 응답을 다시 읽는다 — `listHome` 이 받은 `/home`, `showAudit` 가 받은 `/audit`,
바닥줄이 받는 `/version`.  대시보드와 메뉴가 같은 `DASH` 를 읽는다 (11회차 *같은 접근자* 규칙).

| 카드 / 그래프 | 출처 |
| --- | --- |
| 프로젝트 · 분석(리비전) | `/home` 의 프로젝트 · 리비전 수 |
| 산출 행 (최신 리비전) | 프로젝트마다 가장 최근 리비전의 `rows` 합 |
| 최근 개정 변경 | 가장 최근 대조의 서버 `counts` (추가 + 수정 + 이전 태그 + 삭제 후보) |
| 사람이 고친 칸 | 최신 리비전의 `edits` |
| 데이터 위생 | `showAudit` 가 센 0 아닌 항목 수 |
| 개정 변경 도넛 | 같은 `counts` — 수정 칸 = `MODIFIED` + `MODIFIED_BEFORE` |

도넛 색은 **상태마다 고정**이다 (순위로 칠하지 않는다).  첫 안(파랑 · 주황 · 초록 · 빨강)은 색맹 검사에서
적록이 갈리지 않아 버렸고, 검사를 통과한 `#2f5bd8 · #b07614 · #0f8f80 · #c2453f` + 회색(대조 안 함)을 쓴다.
범례에 이름과 수 · 비율을 같이 적어 색만으로 읽지 않게 했다.  그래프에 마우스를 올리면 값이 뜬다.

## 7. 못 잰 것

* 회사 PC 브라우저(사내 표준 크롬 버전)에서의 모양.  결과 탭을 여닫는 데는 `:has()` 를 쓰지 않는다
  (`#main` 의 hidden 을 지켜보고 body 에 `in-results` 를 둔다 · 첫 판이 `:has()` 였고 그러면 오래된
  브라우저에서 결과 탭이 **영영 안 보인다** — 스스로 고쳤다).  결과 머리 아래 줄을 비었을 때 접는 데만
  `:has()` 가 남고, 모르는 브라우저에서는 빈 줄이 하나 보일 뿐이다.
* 실 DB 의 위생 경고 내용 — 이 환경의 사본으로만 찍었다.
