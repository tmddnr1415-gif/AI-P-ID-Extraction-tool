hotfix109 — DCS HMI 그래픽 (식별된 P&ID 로 그림 · LOGIC 시뮬레이션과 같은 태그로 연동)

무엇이 달라졌나
 · P&ID 결과 화면 더보기 ▾ [DCS 그래픽] 이 새 HMI 화면으로 열립니다 — 어두운 DCS 풍, 배관 색(계통) · 흐름 화살 · 계기/밸브/기기 심볼 ·
   Symbol & Legend · Control Mode · Trend · Key Parameters · 페이스플레이트.  자리는 P&ID 좌표 그대로이고 그림을 지어내지 않습니다.
 · 태그는 그림에서 두 번 눌러 고칩니다 (누가 고쳤는지 남고, 다시 분석해도 남습니다).  Key Parameters 목록 · Trend 태그도 고를 수 있습니다.
 · "예시 화면" — 참고 그림(압축기 트레인)을 같은 부품으로 다시 그린 본보기 (값은 가짜).
 · LOGIC 검토 화면 도구줄에 🖥 DCS 그래픽 — 같은 이름의 P&ID 프로젝트에서 가장 최근 실행 P&ID 그래픽을 새 창(다른 모니터)으로 엽니다.
   LOGIC 시뮬레이션에서 신호를 주면 같은 태그(TAG NO.)의 계기 · 밸브가 그림에서 켜지고(ON/OFF · OPEN/CLOSED · 경보 · 운전),
   그림에서 요소를 누르면 LOGIC 이 그 태그 행으로 갑니다.  같은 이름의 P&ID 프로젝트가 없으면 목록에서 고릅니다.

어디서 보나
 · http://<서버>:8000/dcs?job=<P&ID 분석> (P&ID 결과 화면의 더보기 ▾) · http://<서버>:8000/dcs/demo (예시)
 · LOGIC 검토 화면 → 🖥 DCS 그래픽 (단추에 "태그 N/M" 이 연동된 태그 수)

주의
 · 실행(태그 있는) P&ID 에서만 그래픽이 만들어집니다.  LOGIC 프로젝트 이름과 P&ID 프로젝트 이름을 같게 두면 바로 열립니다.
 · 태그가 없는 LOGIC 행은 보낼 이름이 없어 그림이 움직이지 않습니다.
