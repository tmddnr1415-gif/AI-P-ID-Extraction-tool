압축·중단 대비.  **재개하면 이 파일을 먼저 읽는다.**

## 이 회차의 성격

**한 가지만 한다.**  목표는 "고쳤다" 가 아니라 **"왜 두 번이나 못 잡았는가"** 다.

```
2차 피드백   별표 있는데 SCT — 여러 장
16회차       "전수 검사 0건" → 거짓.  검사가 자기 자신에게 물었다
3차 피드백   같은 지적 반복
18회차 [C]   p35 5행 수정.  "범례는 뜻을 정하지 축척을 정하지 않는다"
4차 피드백   같은 지적.  이번엔 p25 · p27 · p30
```

**★ 18회차가 "p35 만 축척이 다르다" 고 했는데 p25·p27·p30 이 여전히 SCT 다.**
**따라서 이 셋은 축척 문제가 아니다.  다른 원인이 최소 하나 더 있다.**

## 절대 어기지 않는 것

- **판정 함수(`find_marks`·`read_vendor_mark`)로 "별표가 있는가" 를 세지 않는다** —
  16회차가 이 함정에서 거짓 0 을 냈다.  독립 경로로 센다
- **원인 하나만 고치고 끝내지 않는다** — 두 번 반복된 이유일 수 있다
- 페이지 번호 · 도면번호 · 태그명으로 분기 금지
- 허용치는 범례·도면에서 유도.  근거 없이 넓히지 않는다 (§2.1 ②)
- 행 1037 · Q'ty 1931 불변 (SCOPE 는 열 값이다)
- 실 DB(`app/_data/`) 를 어떤 이유로도 건드리지 않는다
