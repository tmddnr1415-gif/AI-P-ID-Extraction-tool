hotfix112 — P&ID 분석 · LOGIC 검토 · 판넬 공간확보를 한 서버(8000)에서 · 한 꾸러미로

무엇이 들어 있나
  · 이 꾸러미 하나에 지금까지의 P&ID 분석(hotfix111 까지) · LOGIC 검토 · 판넬 공간확보 · DCS 그래픽이 모두 들어 있습니다.
    (앞 꾸러미를 적용했든 안 했든 그대로 덮을 수 있습니다.)
  · 세 화면 모두 같은 P&ID 서버(포트 8000)에서 돕니다 — 서버를 따로 켤 필요가 없습니다.
      P&ID 분석      http://<서버PC>:8000/
      LOGIC 검토     http://<서버PC>:8000/logic
      판넬 공간확보  http://<서버PC>:8000/space
  · 판넬 자료는 운영 PID 폴더의 데이터(space\<프로젝트>\) 에 저장됩니다.  예전에 대시보드에 저장해 둔 판넬 자료는
    판넬 첫 화면의 [대시보드 자료 가져오기] 한 번으로 같은 이름 그대로 옮겨집니다 (여러 번 눌러도 한 벌만).

적용 순서
  1. PID_dev 폴더에서 apply_to_PID_dev.bat 더블클릭
  2. 운영 PID 폴더에서 apply_to_PID_ops.bat 더블클릭 (서버 파일만 · 회사에서 따로 고친 파일이 있으면 아무것도 안 바꾸고 멈춥니다)
  3. 서버가 다시 켜지면 첫 화면 오른쪽 아래 "업데이트 hotfix112" 확인
  4. P&ID 를 다시 분석하면 DCS 그래픽에 기기 이름이 전부 나옵니다 (hotfix111 내용)

대시보드 쪽에서 할 일 (한 줄)
  · 대시보드 메뉴 '판넬 공간확보' 의 주소를 P&ID · LOGIC 메뉴와 같은 방식으로
      <pidBase>/space?embed=1&user=<로그인 이름>
    으로 바꿔 주세요.  이 줄은 대시보드 코드 쪽에서 고칩니다.
