# hotfix51 — 자동 시작 창에서 서버가 뜨지 않던 것 (배치 파일의 한글)

현장(회사 PC 사진 셋): `install_autostart_lan.bat` 는 *"SUCCESS: The scheduled task "PID_Extract_LAN" has
successfully been created"* 까지 나왔는데 `localhost:8000/?embed=1&mode=bid` 가 **ERR_CONNECTION_REFUSED**.
서버 창(`P&ID 분석 서버 (사내망 · 포트 8000)`)에는 다음이 줄줄이 찍혀 있었다:

```
'twork' is not recognized ...        'loopback' ...        'data\CZE_Field_Instrument.xlsx' ...
'"C:\Users\SAMSUNG\.claude\pid\AI-P-ID-Extraction-tool\"' ...   'HOST' ...   'E_Field_Instrument.xlsx)' ...
'uble-click' ...   'yxl'' ...   't' ...   '모드:' ...   'cho' ...   'YPORT)))"' ...   'ho' ...
```

**엔진·서버·화면 0줄.**  바뀐 것은 배치 파일 여섯과 시험 · 문서뿐이다.

## 1. 원인

찍힌 낱말이 전부 `start.bat` 의 **주석과 echo 줄의 조각**이다 — `twork` ← *network*, `loopback`, `uble-click` ←
*double-click*, `data\CZE_Field_Instrument.xlsx` ← `--verify` 설명, `ho` · `cho` ← *echo*, `모드:` ← `echo 사내망 모드:`.
cmd.exe 가 **줄 가운데부터** 읽고 있었다.

* hotfix50 의 `run_lan_service.bat` 가 `chcp 65001`(UTF-8) 을 한 뒤 `call start.bat` 했다.
* `start.bat` 은 **UTF-8 한글이 든 LF 줄끝** 파일이었다.
* cmd.exe 는 배치 파일을 한 줄씩 읽은 뒤 **바이트 위치로 다시 찾아** 다음 줄을 읽는다.  코드페이지 65001 에서 여러
  바이트 글자가 든 줄을 지나면 그 위치 계산이 어긋나고, LF 줄끝은 어긋남을 바로잡지 못한다 → 다음 읽기가 엉뚱한
  바이트에서 시작한다.  그래서 서버를 띄우는 줄(`uvicorn`)에 끝내 닿지 못했다.
* 예전에 `start.bat` 을 **그냥 더블클릭**했을 때는 코드페이지가 949 라 한글 바이트가 깨져 보일 뿐 위치는 맞았다.
  hotfix50 이 `chcp 65001` 을 더해 이 덫을 처음 밟았다.

⚠ **이 환경(Linux)에 cmd.exe 가 없어 bat 를 실행해 보지 못했다** — hotfix50 보고서가 그렇게 적었고 그 자리에서 터졌다.

## 2. 고친 것

| 파일 | 고침 |
| --- | --- |
| `start.bat` · `build.bat` | 화면 문장을 영어로 · **ASCII 만** · **CRLF** |
| `run_lan_service.bat` | `chcp` 없음 · `start.bat` 을 **부르지 않고** 서버를 직접 띄운다 (`.venv` 의 python → `python -m uvicorn app.main:app --host 0.0.0.0 --port 8000` · 옆에 exe 가 있으면 `PID_Extract.exe --lan --no-browser 8000`) · 창 이름 `PID server - LAN port 8000` · 멈추면 10초 뒤 다시 |
| `install_autostart_lan.bat` · `uninstall_autostart_lan.bat` · `open_firewall_8000.bat` | `chcp` 없음 · 영어 문장 · ASCII · CRLF (명령은 hotfix50 그대로) |

한국어 안내는 배치 파일이 아니라 Python 쪽(서버 · 화면)이 말한다 — Python 은 콘솔에 코드페이지와 상관없이 쓴다.

## 3. 시험

`tests/test_hotfix51_bat_ascii.py` 3건 — 저장소의 **모든** `*.bat` 이 ASCII · CRLF(외톨이 LF 0) · 명령 줄에 `chcp` 없음 ·
서비스 파일이 `start.bat` 을 부르지 않고 `uvicorn … --host 0.0.0.0 --port 8000` 과 exe 갈래를 갖는다.
빠른 시험 790 → **793** 통과.  bat 안의 Python 한 줄(`lan.urls`)은 여기서 실행해 주소 둘이 찍히는 것을 확인했다.

## 4. 회사 PC 에서 할 일

1. 열려 있는 `P&ID 분석 서버` 창(오류가 찍힌 창)을 닫는다.
2. hotfix51 꾸러미를 덮어쓴다.
3. `install_autostart_lan.bat` 를 다시 더블클릭한다 (같은 이름의 작업을 덮어쓰고 지금 켠다).  방화벽은 다시 열 필요 없다.
4. 작업 표시줄에 `PID server - LAN port 8000` 창이 생기고 그 안에 `Uvicorn running on http://0.0.0.0:8000` 이 보이면 된다.
5. `http://localhost:8000/?embed=1&mode=bid` 를 다시 연다.

## 5. 못 잰 것

Windows cmd.exe 에서의 실제 실행 — 여기에 없다.  안 뜨면 그 창의 마지막 몇 줄을 사진으로 받아야 한다.
