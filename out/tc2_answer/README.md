**무엇인가**: Claude Code 가 **그 문서의 범례를 판정 기준으로 삼아** 도면만 보고
센 목록.  TC2 는 발주처 리스트가 없어 지금까지 정밀도를 잴 축이 없었고, 이것이
그 자리를 채운다.

**규율** (46회차 프롬프트)
1. "눈에 보인다" 가 아니라 **범례 정의에 맞는다** 로 판정한다 → `legend.md`
2. 확신도 HIGH / MEDIUM / LOW 를 칸마다 적고 **HIGH 만 정답지에 넣는다**
3. 근거를 못 적으면 HIGH 가 아니다
4. 판정을 뒤집으면 기록한다
5. 도면에 무엇이 있는가만 담는다 — **발주처 계상 관행은 도면 밖이다**
6. **오버레이와 코드 행을 보기 전에** 도면을 센다

## 이 방식으로 알게 된 것 — **코드가 못 보는 종류**

1. **절대 pt 로 적힌 창**이 다른 종이에서 그대로 걸린다 (MOV `act_box` 9.0 ↔
   TC2 `M` 원 7.08).  정답지가 그 진단을 독립적으로 재현했다.
2. **ISA 표에 있는데 앵커 사전에 없는 글자**가 있다 (`PP` = 압력 테스트포인트).
   범례가 정의하고 도면이 인쇄하는데 코드 어휘에 없다.
3. **별표를 하나 빠뜨려도 조용하다** — 같은 줄의 세 버블 중 둘만 `VENDOR(SE)`
   가 되고 하나는 `SCT` 로 나간다.  행 수도 지문도 정상으로 보인다.
4. **범례에 있는 기타 심볼(트랩 `ST` · 공급자 인터페이스 `SE▶◀SCT`)** 은
   계기도 밸브도 아니다 — 정답지가 그것을 **세지 않는 근거**를 준다.
