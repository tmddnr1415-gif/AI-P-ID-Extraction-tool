## 스키마 — 이번 회차에 늘어난 열은 **없다**

1. `job.engine_json` **안의 키 하나**(`legend_profile`) — 열이 아니라 JSON

   그것을 `mode: unknown` 으로 그대로 말한다 (없는 것을 "유도했음" 으로 읽지
   않는다).

   `app/_data/` 안이므로 갈음 대상이 아니다.  코드를 덮어써도 사라지지 않는다.
