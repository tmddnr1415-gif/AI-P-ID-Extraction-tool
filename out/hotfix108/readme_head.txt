hotfix108 — 절전모드 (P&ID 분석 · LOGIC 검토 · 판넬 공간확보 · DCS 그래픽 공용)

무엇이 달라졌나
 · 서버(8000)가 꺼져 있어도(부서장 PC 절전 · 서버 멈춤) 한 번 열어 본 화면과 자료로 계속 봅니다.
   화면 위에 "절전모드 — 서버에 연결할 수 없습니다" 알약이 뜹니다.
 · 그동안 고친 것(칸 편집 · 삭제 · O/X · 메모 · 핀 · 승수 · LOGIC 사람 값 · 메모 · 판넬 저장 · 노트)은 이 PC 의 브라우저에
   보관됐다가, 서버가 켜지면 보관한 순서대로 다시 보내 서버 값을 덮어씁니다 (알약: "서버에 덮어썼습니다 — N건").
 · 서버가 켜져야 하는 일(분석 · 시뮬레이션 · Excel · 제안 · 삭제)은 절전모드에서 "서버가 켜져야 할 수 있는 일" 이라고 거절합니다.
 · 알약의 [절전 대비 보관] — 지금 결과(장 그림 포함) · LOGIC 묶음 · 판넬 자료를 미리 담아 둡니다.  담아 두지 않은 자료는
   서버가 꺼졌을 때 "이 PC 에 보관돼 있지 않습니다" 로 뜹니다.
 · 알약의 [보관된 변경] — 아직 못 보낸 것 · 서버가 받지 않은 것 목록 (다시 보내기 · 버리기).

어디서 보나
 · 각 화면을 http://<서버>:8000/… 으로 한 번 열면 보관이 시작됩니다 (브라우저 저장소 — PC 마다 따로).
 · 서버 로그에 되보낸 요청이 "[offline replay] …" 로 남습니다.

주의
 · 꺼진 동안 다른 사람이 같은 칸을 고쳤으면, 켜질 때 이 PC 의 보관본이 그 값을 덮습니다 (지시대로 "덮어쓰기").
 · 서버 파일을 얹은 뒤 서버를 다시 켜야 합니다 (/sw.js · /offline/shell 이 새로 생깁니다).
