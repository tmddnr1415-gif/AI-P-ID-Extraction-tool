# L56 — LOGIC 작도: 묶음 · FROM/TO · 매크로 타입 · 학습한 크기 · 입력 로직 재현 (2026-10-25)

사용자 요구: *"From-To 는 당연히 이어져야 하고, 매크로는 타입별로 모두 반영, 크기와 배치는 다른 로직을 참고,
입력된 로직을 동일하게 만들 수 있는 작성 프로그램"* · *"쉽게 그릴 수 있어야 하고 · 노트 · time delay 등 모든 설정을
그릴 때 · 이후 시뮬레이션의 모든 기능을 선택적으로."*

## 무엇이 달라졌나 (화면에서 보는 것)

1. **묶음(여러 장)** — 시트 카드 옆 '묶음' 카드.  `묶음으로 만들기` → `장 더하기`(Typical 표시 가능) → 장 목록에서 옮겨 다닌다.
   오른쪽 TO 칸에 `G002-2` 처럼 적고 저장하면 **받는 장의 FM 칸이 저절로 채워지고**(설명도 베껴 온다) 칸이 초록으로 · `↗` 를
   누르면 그 장 그 행으로 간다.  어긋나면 붉게 · 설명만 다르면 주황.  판정은 LOGIC 검토가 쓰는 from-to 점검 **그대로**다.
2. **매크로 블록** — 묶음의 Typical 장(또는 학습 사전의 Typical)이 '매크로' 카드에 타입으로 오른다.  누르면 단자 이름이 든 큰
   상자가 놓이고, 검토로 보내면 분석기가 그 Typical 과 잇는다 (묶음 검증이 `매크로→T001` 로 확인한다).
3. **분석한 묶음 가져오기** — 분석한 로직 묶음 전체를 같은 양식의 그림 묶음으로 들여온다 (`묶음 가져오기`).  재현율은 아래 표.
4. **크기 · 배치** — 기호 기본 크기를 세 프로젝트(HRSG · 1A5J · 1A1Y)에서 잰 값(행 간격 배율)으로 (`config/logic_draw_style.json`).
5. **그릴 때 모든 설정** — 타이머 시간 · 투표 A/B · 메모리 우선 칸 · 연결 기호 방향 · 매크로 단자에 더해
   **블록 위 글**(설정값 `202.4 barg` — 감시 블록이면 시뮬레이션 초기값) · **선 아래 글**(`0~250 barg` 아날로그 범위) ·
   **장 노트**(시트 카드 · 한 줄에 하나 → 장 아래 NOTES 상자에 번호 붙여 인쇄 · 분석기가 NOTE 문장을 읽는다).  한글도 인쇄된다.
6. **검토 화면 ↔ 그림** — 작도에서 올린 묶음을 LOGIC 검토에서 열면 머리줄에 `✎ 이 그림으로` 가 보인다.  고친 뒤 다시 올리면 된다.
   올린 묶음은 보통 분석과 같아 시뮬레이션 · 순차 동작 · 정합성 검토 · 그룹 시험을 그대로 쓴다.
7. **편하게** — Ctrl+C / Ctrl+V (블록과 그 사이 선까지 · 한 행 아래로) · Ctrl+D 복사 · L55 눈금자 · 모눈 · 정렬 안내선.
