# [B] SCOPE — 사각형이 아니라 **그려진 윤곽**으로 가른다

## 1. 무엇이 틀려 있었나

29회차 [E-3] 이 태그 감사로 찾아낸 결함이다.  UAD p23 의 `00GKB01CL001A`(SCT)
↔ `00GKB01CL001B`(VENDOR) 은 같은 자리에 위아래로 선 LIT 한 쌍인데,
**렌더에는 두 버블 어디에도 별표가 없다**.  B 행이 주장하는 마크는 좌표
(215.58, 260.03) — 버블 사각형 `[193.2, 252.1, 222.9, 263.4]` **안쪽**이고,
거기 있는 것은 별표가 아니라 **SHX(획)로 그린 태그 글자**다.

UAD 는 글자를 획으로 플롯하므로 글자 한 덩이가 `_glyph_clusters` 에 별표
크기의 획 뭉치로 잡힌다.  AL NOUF1·SADARA·TC2 는 그런 일이 없다 — 그 세
문서는 버블 안 글자가 **활자**이거나 크기가 다르다.

## 3. 채택 — 스타디움 윤곽에 대한 점-포함 판정

`find_bubbles` 는 처음부터 윤곽을 알고 있었다 — 버블은 *마주 본 호 캡 둘 +
곧은 옆면* 으로 찾는다.  **바깥 사각형만 돌려주느라 캡을 버렸을 뿐이다.**
찾고 있는데 안 쓰던 것의 **열한 번째**다 (§9 3③ · 13·15·16·18·22·24·25·27·28회차).

```
윤곽(가로 스타디움) = 곧은 부분 [cap_a.x1, cap_b.x0] x [y0, y1]
                     + 왼쪽 캡 타원 (중심 cap_a.x1 · 반축 cap_a.width x 높이/2)
                     + 오른쪽 캡 타원 (중심 cap_b.x0 · 반축 cap_b.width x 높이/2)
```

* **새 상수가 하나도 없다** — 검출이 이미 잰 캡 사각형을 그대로 쓴다.
* **반지름을 가정하지 않는다** — AL NOUF1 의 캡 비율은 ≈2.0(반원)이지만
  TC2 는 34x11 ≈3.1 로 얕다.  가정하면 TC2 에서 틀린다.
* **윤곽을 못 찾으면 걸지 않는다** — 밸브 몸체는 스타디움이 아니다.
  모르는 것을 글자로 읽지 않는다.
* **획으로 그린 것에만 건다.**  활자 `*`(`MARK_TEXT_RE`)에는 걸지 않는다 —
  그것이 별표라는 것을 우리가 *안다*.  획 뭉치는 *추론*이다.
* **크기 학습에도 건다** (`drawn_mark_sizes`).  안 걸면 글자가 크기를
  가르쳐(`n >= 2`) 그 크기의 얼룩이 다른 자리에서 마크로 인정된다.
