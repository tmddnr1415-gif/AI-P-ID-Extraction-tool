# [C] UAD 카운팅 격차 — 172 계기 태그 ↔ 128 태그 붙은 행

**요구**: 44 를 중복 인쇄와 미검출로 가르고, 미검출은 장·좌표·원인을 적는다.
**결과**: 그 둘로 갈리지 않는다.  실제 갈래는 **넷**이고, 그중 카운팅 실패는
**36건**이다.

---

## 1. 숫자를 다시 세운다

29회차 §5.2 는 "계기(`C*`) 172 ↔ 태그 붙은 행 128, 차이 44" 라고 적었다.
그 44 안에 서로 다른 것이 섞여 있다.

| 층 | 수 | 무엇인가 |
| --- | ---: | --- |
| 행 있는 장의 서로 다른 계기 태그 (`C*`) | **172** | 분자의 모수 |
| └ 행이 선 것 | **125** | |
| └ 행이 없는 것 | **47** | 아래에서 가른다 |
| 행에 붙은 태그 중 `C*` 가 아닌 것 | **3** | p23 `…BP101` ×3 (RO) |
| **태그 붙은 행 합** | **128** | 125 + 3 |

즉 "44" 는 **47 − 3** 이었고, 47 을 가르는 것이 이 절이다.

## 2. 47 을 가른다

| 갈래 | 수 | 판정 |
| --- | ---: | --- |
| ㉠ A/B 쌍의 **묶음 이름** | **11** | 카운팅 실패가 **아니다** |
| ㉡ 다중 신호 버블 (`CL101`) | **21** | 미검출 |
| ㉢ 네모 상자 심볼 (`CF001/002` — FLOW METER) | **8** | 미검출 |
| ㉣ `AIT`/`AIA` 계열 (`CQ001/002`) | **2** | 미검출 — 이미 알려진 것 |
| ㉤ 나머지 (`CP001`·`CP501`·`CL001`) | **5** | 미검출 |

### ㉠ 묶음 이름 11 — 실패가 아니다

`00GHB01CL001` 는 행이 없지만 `00GHB01CL001A` · `…B` 두 행이 **있다**.
도면이 한 쌍을 가리킬 때 접미 없이 한 번 더 인쇄한 것이고, 물리 계기는
두 개이며 행도 두 개다.  **하나로 세는 것이 맞고 지금 그렇게 되고 있다.**

### ㉡ `CL101` 21건 — 원인은 **경보 접미가 붙은 앵커 낱말**이다

렌더: `7_캡처/UAD_미검출_p30_00GMA01CL101.png`

한 태그가 **세 번** 인쇄돼 있고 각각 버블이 하나씩이다:

```
LSA++            00GMA01CL101      (네모 테두리 = 원격)
LSA++,+,-,--     00GMA01CL101      LCP
LS++,+,-,--      00GMA01CL101
```

세 버블은 **물리 계기 하나**의 세 신호다 — AL NOUF1 의 LS 묶음(34묶음
102버블 → 34행)과 같은 구조다.  그런데 **한 행도 서지 않았다.**

원인은 앵커가 **낱말 통째 일치**라는 것이다.  `ds.detect` 는
`for r, t in pc.words: if t not in rules.anchors: continue` 로 도는데,
이 도면은 경보 수식자를 글자에 **붙여서** 인쇄한다 — `LSA++` · `LS++,+,-,--`
· `PIA+,-` · `TIA+,-` · `PDIA++,+`.  `LS` 가 아니므로 후보에도 못 든다.

**증거**: 미판정 심볼 목록 62건에 `LSA`·`LS` 가 **한 건도 없다**
(`LIT` 27 · `PDIT` 13 · `RO` 6 · `PDIA` 3 · `TIA` 2 · `PI` 2 · `AIT` 2 …).
버블 검증 실패가 아니라 **낱말이 앵커 사전에 안 걸린 것**이다.

⚠ **이번 회차에 고치지 않았다.**  앵커 매칭을 넓히는 것은 검출 변경이고
AL NOUF1 에 행을 더할 수 있다.  [금지] 의 *"미검출 원인 규명 없이 검출 조건
완화"* 를 지키되, 규명은 끝났으므로 **다음 회차 1순위**로 넘긴다.
근거는 범례에 있다 — UAD p4 ISA 문자표가 후속문자를 인쇄한다.

### ㉢ `CF001/002` 8건 — 버블이 아니라 **네모 상자**다

렌더: `7_캡처/UAD_미검출_p8_11EKG60CF001.png`

`11EKG60CF001` 은 `FLOW METER` 라고 글자를 적은 **사각형**이고 그 둘레가
`NOTE 7` 파선 상자다.  스타디움 버블이 아니므로 `find_bubbles` 가 찾을
대상이 아니다.  **범례가 이 심볼을 정의하는지 확인한 뒤 등록 화면(18회차
[D])으로 보내는 것이 맞는 길**이고, 억지로 검출 조건을 넓히는 자리가 아니다.

### ㉣ `CQ001/002` 2건 — `AIT` 는 이미 알려진 미판정

렌더: `7_캡처/UAD_미검출_p23_00GKB40CQ001.png` (개정 클라우드 안에 있다)

`AIT` / `AIA+,-` 버블이다.  18회차 [G] 가 이미 잰 자리 — AL NOUF1 에서
`AT`·`AIT` 앵커를 넣으면 축2 정밀도가 89.1 → 88.3 으로 **게이트를 못 넘는다**.
UAD 의 미판정 목록에는 `AIT` 2건으로 **이미 올라와 있다** (등록 화면 대상).

## 3. 반대 방향 — 태그가 없는 행 21개

행 149 중 태그가 안 붙은 21행은 **도면이 태그를 안 찍어서**다.

* p25 는 19행 중 4행만 태그가 붙는다.  15행의 버블 **안에 있는 낱말은
  TYPE 하나뿐**이다 (`PI` · `TIT` · `PDIT` · `PIT`) — 태그가 없다.
* 태그 없는 21행에서 가장 가까운 "코드 모양" 낱말까지의 거리:
  40pt 안 **5행**뿐이고, 그 5행의 1위 후보는 `EKG4` · `AA605` · `X100%)` ·
  `00GCN44AA051`(밸브 태그)로 **계기 태그가 아니다**.
* 즉 **놓친 태그는 0 이다.**  도면이 말하지 않으면 사람에게 묻는다 (§9 ⑤).

## 4. 목록 시트 p16·p17·p18

* 계기 모양 태그 낱말 **180개**가 인쇄돼 있고 검출은 **0** 이다.
* 세 장 전부 `page_kind` 가 PID 가 아니어서 **분석 대상(`targets`)에서 빠진다**
  — 행도 0, 사람이 볼 장에서도 빠진다.  **검출 0이 맞다.**
* p10 (1개) · p32 (3개)도 같은 갈래다.

## 5. 정리 — 무엇이 카운팅 실패인가

```
계기 태그 532 낱말 (서로 다른 것 443)
 ├ 행 없는 장 184     목록·표지 시트 (p16·17·18·10·32) — 정상
 └ 행 있는 장 275 (서로 다름)
    ├ 기기·밸브(A*) 79 · 용기(B*) 24     계기가 아니다
    └ 계기(C*) 172
       ├ 행이 선 것 125
       ├ 묶음 이름 11                     정상
       └ **미검출 36**  ㉡21 ㉢8 ㉣2 ㉤5
```

**카운팅 실패는 36건이고, 그중 21건(58%)이 한 원인 — 경보 접미가 붙은 앵커
낱말 — 에서 나온다.**  다음 회차에 그것 하나를 고치면 격차의 절반 이상이
닫힌다.
