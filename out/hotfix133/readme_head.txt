무엇이 바뀌었나
P&ID
- Excel 로 내보낼 때 '=' 로 시작하는 글을 수식이 아니라 글 그대로 씁니다 · PDF 안의 제어 문자로 멈추지 않습니다.

LOGIC (L87–L91)
- LOGIC 작도: 단자에서 끌어 선 잇기 · ＋ 빠른 잇기 · 찾기 · 작은 지도 · 임시 저장 (draw.io 방식).
- 기호 · 매크로를 큰 새 창으로 — 누르고 그림에서 놓을 자리를 누르기.
- 분석한 Logic 을 불러와 같은 모양으로 다시 그리기 (19VA 827장 · 95% 이상) · 원본 표 아래 NOTE 도 그대로.
- 기호를 두 번 누르면 설명 · 직접 해 보기, 매크로를 두 번 누르면 내부 동작 · 고치기.
- 매크로를 이 프로젝트에만 고치기 (사전 Typical 을 프로젝트 사본으로 열어 시뮬레이션 · 고치기 · 저장).
- 업로드 검사에서 거절한 PDF 도 바로 닫습니다.

판넬 공간확보 (ROOM SIZE 계산)
- 첫 화면: 프로젝트 아래 Phase 1 · 계획 / Phase 2 · 건축 도면 으로 나눔.

- Phase 결과 출력: PDF(도면 + 요약 · Equipment List) + CAD(DXF) + 3D HTML.
