# 가상 광장 (부여성 남쪽) — 대시보드 개발 창으로 인계

부서원이 바람의나라 느낌의 도트 캐릭터로 돌아다니며 대화하는 작은 메타버스입니다.  P&ID 추출 도구
저장소에서 시작했고, **이제부터는 부서 대시보드 개발 창에서 이어서 만듭니다** (P&ID 쪽에서는 더 손대지 않습니다).

## 1. 지금 되는 것

| 기능 | 내용 |
| --- | --- |
| 이동 | 화면을 한 번 누르고 **키보드 방향키 ←↑→↓** 로 한 칸씩 걷기 (한글 입력기가 켜져 있어도 걷습니다) |
| 대화 | **Enter → 글 → Enter** — 머리 위 말풍선 `이름 : 말` 7초 · 왼쪽 아래 대화 기록 · Esc 는 쓰던 글 취소 · 한 마디 80자 |
| 공격 | **Space** — 바라보는 쪽으로 목검을 휘두름.  앞 칸(또는 같은 칸)에 선 사람이 붉게 번쩍 + 흔들림 + "퍽!" (맞는 사람은 서버가 가림 · 0.3초에 한 번 · 체력/점수 없음) |
| 배경 | 바람의나라 '부여성 남쪽' — 주황 흙마당 · 생울타리 잔디 · 남문과 성벽 · 붉은 꼰 나무틀 · '부여성 남쪽' 현판 · 한옥 · 우물 · 장승 · 청사초롱 · 장터 |
| 역할 머리 장식 | 그룹장 = 왕관 · 유닛장 = 날개 달린 관모(사모) · 부서원 = 관모 · 운영자 = 노비 차림(두건 · 무명옷).  이름 앞 칭호 `[그룹장]` … **서버가 정합니다 (자기가 고를 수 없음)** |
| 얼굴 바꾸기 | 오른쪽 아래 [얼굴 바꾸기] — 머리 모양 10 · 머리 색 8 · 피부 4 · 눈 5 · 수염 4 · 옷 색 12 · 바지 색 6 · 돌아가는 미리보기 · 무작위.  이름마다 서버 파일에 남음 |
| 역할 지정 | 운영자 화면에만 [역할 지정] — 그룹장 · 유닛장 · 부서원 · 운영자를 이름마다 바꿈 |
| 접속자 | 오른쪽 위 '광장에 있는 사람' (역할 순) · 들어옴/나감 알림 |

그림 파일은 하나도 없습니다 — 지도 · 소품 · 캐릭터 전부 `static/plaza.js` 가 canvas 로 그립니다.

## 2. 파일

| 파일 | 하는 일 |
| --- | --- |
| `static/plaza.html` · `plaza.js` · `plaza.css` | 화면 (그대로 씀) |
| `plaza_server.py` | **표준 라이브러리만** 쓰는 서버 (pip 불필요 — 대시보드와 같은 조건).  P&ID 서버의 FastAPI 판(`app/plaza.py`)과 **길 · 응답이 같습니다** |
| `selftest.py` | 서버 자가 점검 — `python selftest.py` → "모두 통과" |
| `screens/` | 스크린샷 (대시보드 흉내 화면 안에서 4명이 걷고 · 말하고 · 때리고 · 얼굴/역할을 바꾼 모습) |

## 3. 돌리는 법

```bat
python plaza_server.py --port 8100 --data C:\Claude\Dashboard\plaza_data
```

- 브라우저: `http://<서버 PC>:8100/plaza?embed=1&user=<로그인 이름>`
- `--data` 폴더에 `roles.json`(역할 · 처음 켜면 빈 틀이 생김) 과 `looks.json`(얼굴) 이 생깁니다.
- **처음 한 번**: `roles.json` 의 `"operators": []` 에 운영자 이름 하나를 손으로 적습니다.
  그 뒤로는 광장 화면의 [역할 지정] 에서 바꿉니다.
- 사내망(사설 주소 · 루프백) 밖에서 오면 403 입니다.  `/version` 하나만 다른 출처 fetch 를 허용합니다.
- 대화 · 위치는 메모리에만 있어 서버를 다시 켜면 광장이 빕니다 (역할 · 얼굴은 파일이라 남음).

## 4. 대시보드에 넣는 모양 (사용자 요구)

- **메뉴를 따로 만들지 않는다.**  첫 화면 '최근 변경 이력' 카드를 **반으로 접을 수 있게**(기본 접힘 · 단추 "펼치기 ▾ / 반으로 접기 ▴")
  하고, **그 바로 아래** '가상 광장' 카드에 iframe 하나 (높이 약 470px · 테두리 없음 · sandbox 쓰지 않음).
- iframe 주소에 `user=<로그인 이름>` (encodeURIComponent).  홈을 다시 그릴 때 iframe 을 새로 만들지 않는다
  (새로 만들면 캐릭터가 나갔다 다시 들어온다).

## 5. 지켜 온 규칙 (바꾸려면 이유를 적고)

1. **사람이 적은 글은 HTML 로 넣지 않는다** — 이름 · 말은 canvas 글자와 `textContent` 로만 (다른 사람 화면에서 스크립트가 돌 수 있다).
2. **prompt / confirm / alert 를 쓰지 않는다** — 대시보드 iframe 이 막는다.  화면 안 판으로.
3. **역할은 서버가 정한다** — 화면이 보낸 역할을 믿지 않는다.  역할 바꾸기는 운영자만 (서버가 403).
4. **맞는 사람은 서버가 가린다** — 화면은 그림만.
5. 외형 칸 개수(`LOOK_RANGES`)는 서버와 `plaza.js` 의 표(`HAIRS` · `HAIRC` · `SKINS` · `EYES` · `BEARDS` · `CLOTHS` · `PANTS`)가 같아야 한다.
   표를 늘리면 둘 다 고친다.
6. 이름 해시는 **부호 없는 수**로 자른다 (`>>>`).  `>>` 면 음수 → 빈 색 → 그리기가 통째로 멈췄다 (실제로 겪음).
7. 방향키는 `ev.code` · `ev.key` · `ev.keyCode` 를 다 본다 — 한글 입력기가 켜진 PC 는 key 가 `Process` 로 온다.
8. 지도 크기 `MAP_W × MAP_H = 56 × 32` 는 서버와 `plaza.js` 의 `W` · `H` 가 같아야 한다.
