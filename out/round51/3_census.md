## ㉢ 증명 — 두 채널로 셌습니다

### ① 버블 안 낱말 (네 프로젝트 · 50회차가 PG·TG 에 쓴 방법)

버블 안 1~5글자 대문자 낱말은 앵커가 아니어도 **전부** `unjudged_symbols` 에
담깁니다 (`detect()` 의 `unmapped` — `len(hit) == 1` 로 버블을 확인한 뒤).
**네 프로젝트 미판정 목록에 `TG` · `PG` · `SG` · `PV` · `LV` · `TV` · `FV` 가
한 건도 없습니다.**

### ② 인쇄된 낱말 (AL NOUF1 · PDF 가 있으므로)

58장 전체에서 1~5글자 대문자 낱말 **19,322개**를 세어 종류 **618개**를 냈습니다
(`out/round51/printed_AL_NOUF1.json`).

```
TG 0 · PG 0 · SG 0 · PV 0 · LV 0 · TV 0 · FV 0        ← 한 번도 인쇄되지 않음
PCV 9 · LCV 5 · TCV 15 · FCV 10                        ← 이 문서는 C 를 넣어 씁니다
AIT 4 (p16)                                            ← 사용자 화면의 그 넷
```

### ③ 붙여 쓴 형태도 찾았습니다 (㉢ 주장을 깨뜨릴 수 있는 형태)

`PV-101` · `LV101` 처럼 숫자가 붙은 꼴을 정규식 `^(TG|PG|SG|PV|LV|TV|FV)([^A-Z].*)?$`
로 전 낱말에서 찾았습니다 — **0건**.

**결론: 요구 20종 중 `TG`·`PG`·`SG`·`PV`·`LV`·`TV`·`FV` 일곱은 이 네 도면에
없습니다.**  이 도면들은 게이지를 `PI`·`TI` 로, 제어 밸브를 `PCV`·`LCV`·`TCV`
·`FCV` 로 인쇄합니다.  **없는 것을 만들지 않습니다** (§2.1 ③).
