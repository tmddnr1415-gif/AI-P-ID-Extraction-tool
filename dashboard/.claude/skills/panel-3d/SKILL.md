# 판넬 공간확보 3D — 고치는 법

참고한 것: anatomy 뷰어(github.com/thebuggeddev/anatomy, three.js) 의 카메라 움직임(감속 이동 · 자동 회전),
image-blaster(github.com/neilsonnn/image-blaster, Claude 스킬셋) 의 '장면을 기술 조사서처럼 적기' · '들어 옮길 수 있는 것 = 따로 만드는 물체' 규칙.
둘 다 **코드는 가져오지 않음** — 폐쇄망 · 외부 라이브러리 금지라 원리만 순수 WebGL 로 옮겼다.

## 지켜야 할 것
- 외부 라이브러리 · CDN · 외부 API 금지 (three.js 도 안 됨). WebGL 1 + 2D 캔버스만.
- 셰이더는 `V3_VS` · `V3_FS` 한 곳 — 앱(`v3init`)과 3D 보기 HTML(`v3Viewer`, `v3HtmlText` 가 글로 넣음)이 같이 씀. 한쪽만 고치지 않는다.
- `v3Viewer` 는 `toString()` 으로 HTML 에 들어가므로 앱 변수 · 템플릿 글자(백틱) · `</script` 를 쓰지 않는다. 필요한 값은 `v3HtmlText` 의 `D` 로 넘긴다.
- 꼭짓점 형식 10 float: 위치 3 · 색 RGBA 4 · 법선 3. **법선이 0 이면 조명 없음**(선 · 바닥 표시 · 그림자 · 글자용).
- 장면(`v3build`)은 자료가 바뀔 때만 다시 만든다(`V3.dirty`). 매 화면 그리는 것은 `v3dyn`(사람) · `v3light`(재기 선) 뿐.

## 조명
- 꼭짓점 단위 조명 하나만 쓴다 (`V3_VS`): 반구광 + 주광 (0.35,0.85,0.45) + 보조광 (−0.6,0.3,−0.4) + 약한 반사광. 주광 방향은 바닥 그림자 방향(`LS`)과 같아야 한다.
- **'고급 조명'(화소 단위 · ACES 톤 매핑 · 프레넬 림 · 먼 곳 옅게 · 접지 그림자)은 넣었다가 사용자 결정으로 뺐다 (2026-11-07). 다시 넣지 않는다.** 조명 · 색감을 바꿀 일이 있으면 먼저 사용자에게 묻는다.

## 그림자
- 투영 그림자(`SH`, 스텐실로 겹쳐도 한 번만)만 쓴다.

## 카메라
- 시점 단추 · 더블클릭은 `v3tween`(520 ms, 감속 곡선)으로 옮긴다. 바로 건너뛰지 않는다.
- 3D 보기 HTML 은 처음에 천천히 자동 회전(`bAuto`), 끌기 · 휠을 쓰면 멈춤. 시점 단추도 같은 감속 이동.

## 새 물체 넣기 (image-blaster 방식)
1. 사진 · 카탈로그를 **기술 조사서처럼** 적는다: 이름 · 치수(W×D×H) · 재질 · 색(HEX) · 조명 반응(무광/유광) · 개수. '고급스러운', '~처럼 보임' 같은 해석은 적지 않는다. 모르면 비운다.
2. **들어 옮길 수 있는 것만 따로** 만든다(의자 · 모니터 · 프린터 · 판넬). 바닥 · 벽 · 트렌치 · Access Floor 는 장면(실)으로.
3. 같은 것이 여러 개면 모양 함수 하나 + 개수(인스턴스) — 따로 만들지 않는다.
4. 책상+의자처럼 묶은 물체를 만들지 않는다 (배치 · 간섭 검사가 장비 단위라서).
5. 모양은 상자(`box` · `obox` · `limb`) 조합으로 — 면마다 법선을 꼭 준다. 무광 금속은 색을 조금 어둡게, 화면 · 유리는 반투명(`X` 배열).

## 확인
- `node` + Playwright 로 3D 를 열어 같은 시점 3 곳(등각 · 가까이 · 캐비닛) 전후 캡처, 스크립트 오류 0.
- `window.crspaceSpeed()` 그리기 시간: 판넬 30 개 기준 15 ms 아래.
- 3D 보기 HTML 을 따로 열어 그려지는지 · 돌아가는지.
- `DASHBOARD_ARCHITECTURE.md` 변경 이력에 적는다.
