판넬 공간확보

계장 판넬 Type 을 만들어 배치하고 필요 면적 · 권장 실 크기를 건축에 전달합니다. 프로젝트를 고르고 배치 시작을 누르세요.

1 어디에 넣을지

저장은 서버의 이 프로젝트에 날짜별로 쌓이고, 부서원 모두 저장 이력 · 노트를 봅니다.

2 어떻게 시작할지

  • Option A · Equipment List 로 자동 배치List 붙여넣기 → 제약조건(벽 · 판넬 간 이격 …) → Ref 학습값으로 배치 → 이어서 고침
  • Option B · Ref. PJT Room Layout 불러오기눌러서 Ref 고르기
  • 이 룸 · Rev 의 최근 저장본 이어서① 에서 프로젝트 · 룸 · Rev 를 고르면 나옵니다
  • 이 PC 에서 하던 작업 이어서
  • 빈 실에서 새로 배치지금 Panel Type 은 그대로, 판넬 · 노트 없이
  • 예시 배치로 시작System · Marshalling · Rack · PD · UPS 예시
  • 배치안 파일(JSON) 불러오기[배치안 저장 (JSON)] 으로 만든 파일 — 눌러서 고르기

    서버 프로젝트 없음

    건축 전달 요약 머리와 DXF 타이틀 글자 · 파일 이름에 들어갑니다. 작성자를 비우면 대시보드 로그인 이름(회색 글자)을 씁니다 — 저장 파일에는 직접 적은 값만 남습니다.

    2실 치수 (Room) 단위 mm

    항상 막는 것: 기둥과 겹침 · 판넬끼리 겹침 · 다른 판넬의 도어 회전 궤적과 간섭 · 도어 궤적끼리 겹침. Ctrl 을 누른 채 끌면 근처 판넬 · 벽 · 기둥에 맞춰 붙습니다(정렬 안내선).

    기둥 Span을 비우면 기둥 없이 검토합니다. 기둥 하나씩 옮기기 · 추가 · 삭제는 도구줄 [기둥 편집]. 벽 이격 · Spare 는 권장 실 크기 계산에 쓰입니다 (벽 이격은 도면에 상 · 하 · 좌 · 우 끝 판넬부터 보라 빗금으로 표시되고, 실 벽이 그보다 가까우면 경고) (Spare = 필요 영역을 증설 방향으로 그 비율만큼 늘림).

    3Panel Type · 배치

    위 Panel 삽입 줄에서 Type 을 누르면 배치 모드가 되고, 도면을 클릭하면 그 자리에 놓입니다 (연속 N EA 는 옆으로 붙여 놓음 · R = 회전 · Esc = 끝). Type 을 고치려면 ✎ 또는 두 번 누르기.

    W·D = 평면 치수, F·R = 전면·후면 유지보수 공간. 굵은 선이 전면입니다. Door 위치 · 열림(L/R 힌지 · 양개)을 고르면 문짝과 회전 궤적이 그려지고, 궤적이 유지보수 공간 · 벽 · 기둥 · 다른 판넬에 걸리면 경고합니다. Type 치수를 바꾸면 배치된 판넬에 바로 반영됩니다.

    📌 도면 노트 0
