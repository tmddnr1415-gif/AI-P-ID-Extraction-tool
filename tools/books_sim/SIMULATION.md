# 계장도서검토 — 검색 품질 시뮬레이션

부서원이 **말하듯** 검색해도 원하는 책 · 쪽을 찾도록, 인터넷에서 모은 실제 도서로 검색 엔진을 채점하며 고쳤다 (2026-10-24).

## 1. 시험 도서 (63권 · 12,232쪽 · 153 MB → 2차: 67권, 설계 문서 xlsx · pptx · csv · xls 추가)

인터넷 공개 자료 65개 파일 (GitHub · GitLab 에서 받을 수 있는 것만 — 사내 정책상 쓰는 Wikipedia · 제조사 사이트는 이 환경에서 막혀 있었음).
실제 부서 폴더처럼 하위 폴더 · 한글 파일명을 섞음: `계장/{통신, 매뉴얼, 강의자료, PLC, SIS, 제어밸브, 교정, 레벨, 분석기, P&ID}` · `보안` · `전기` · `기계` · `법령` · `기타/{문학, 소설, IT, 심리학, 역사, 요리, 경제, 취미}` · `스캔`.

## 2. 질문

- **조정용 48개** (`queries_dev.json`): 주제 12개 × 말투 4가지 — 짧은 말 · 대화체 · 영어 · 섞어 쓰기
  예) `Transmitter 관련 도서` / `트랜스미터에 대해 설명된 책 있어?` / `압력전송기 영점 조정은 어떻게 해?` / `HART로 PV 값 읽는 방법` / `ladder diagram 배우고 싶어` / `계장 도면 기호 읽는 법`
- **시험용 20개** (`queries_test.json`, 조정에 쓰지 않음): 다른 주제 · 다른 분야 — `열전달 전도 대류`, `리눅스 명령어 배우기`, `무선 송신기 radio transmitter 시험 문제`, `IEC 62443 존과 컨듀잇`, `계량법 검정 기준` …
- **발전 · 플랜트 15개** (`queries_pp.json`, 2차): `HRSG 드럼 수위 3요소 제어`, `터빈 감시계기 TSI 진동 축위치`, `급수펌프 최소유량 재순환`, `API 670 machinery protection`, `증기터빈 과속 트립 보호 로직`, `DCS 이중화 구성 마샬링 캐비닛`, `SIL 검증 PFD 계산`, `케이블 스케줄 정션박스 설계`, `변압기 보호 차동 계전기`, `수처리 전도도 실리카 분석계` … — 시험 도서에 발전소 전문서가 거의 없어(xlsx 계기 목록 · pptx TSI 교육자료 · xls 계산서를 만들어 넣음) **상한이 낮은 묶음**: 질문 15개 중 5개는 정답 책이 폴더에 없다.

지표: **nDCG@10** (상위 10권 순서 품질, 1 = 완벽) · **MRR** (가장 관련 높은 책이 몇 번째에 나오나, 1 = 1위) · **상위 5 방해 도서** 수.

### 2차 (발전 · 플랜트 지식 베이스) — 무엇이 문제였고 어떻게 고쳤나
지식 베이스 `kb.js` 는 2026-10-24 에 인터넷 자료를 찾아 정리했다: API 670 (진동 · 축위치 · 편심 · 과속 보호 채널 구성), HRSG 드럼 3요소 제어 · shrink/swell · 기동 바이패스, 가스터빈 · 증기터빈 보호 시퀀스(과속 · 진동 · 축추력 · 복수기 진공), BFP 최소유량 재순환 · NPSH · API 682 실 플랜, 계장 설계 산출물 목록(Instrument Index · 데이터시트 · 루프 · 후크업 · 케이블 스케줄 · JB 배치), DCS 벤더 · 이중화 · 마샬링, PLC 프로그래밍(IEC 61131-3), 수처리 분석계(전도도 · 실리카 · 용존산소 · pH), 자주 쓰는 규격 목록(ISA · IEC · API · ASME · NFPA). 개념 42개 · 표현 약 1,300개 · 핵심 하위 항목 240개.

| 문제 (붙인 직후 0.893 → 0.762) | 고친 방법 |
|---|---|
| 짧고 약한 표현(`head` · `reset` · `DC`)이 개념을 깨움 — `DC` 가 `DCS` 로 번져 DCS 질문이 전기 책으로 | 개념 깨우기 문턱: 한글 가중치 ≥ .8, 영어 ≥ .85(4자 이상이면 .7), 약어는 3자 이상 .8 또는 .95 이상. 복수형 추정은 4자 이상만 |
| 겹치는 표현(`캐비테이션` → 펌프 · 제어밸브 둘 다) | 한 표현을 여러 개념이 가지면 더 긴 표현을 가진 쪽만 (`shared-exclusive`) |
| `안전계장` 안의 `계장`, `시스템` 안의 `시스` 처럼 부분 문자열로 깨어남 | 원래 질문의 자리(span)로 모아 긴 표현에 포함된 짧은 개념은 버림 · 2글자 한글은 앞뒤가 한글(조사 제외)이면 안 깨움 |
| 심화 개념(`level_adv` 등)이 상위 개념의 자식이 돼 `float · reset` 같은 일반어가 상위 질문에 번짐 | `p:`(상위) 대신 `deep:` — 상위 질문이 심화 표현을 끌어오지 않음 |
| 2쪽짜리 표 · 계산서가 '100% 다룸' 으로 과대 | 다룬 비율은 쪽 수를 최소 8쪽으로 보고 계산 |
| 옛 형식 파일 `최소유량계산.xls` 가 `유량계` 질문에 제목 일치 | 한글 제목 일치는 낱말 단위(낱말과 같거나 낱말이 그 표현으로 시작할 때만) |
| `급수펌프` 처럼 붙여 쓴 복합어가 아무 개념도 안 깨움 | 복합어를 펌프 개념에 직접 등록 (급수펌프 · 복수펌프 · 순환수 펌프 · boiler feed pump …) |
| 파일명만 있는 문서(xls · 스캔본)가 본문 있는 책에 늘 밀림 | 질문 낱말이 파일명에 많이 들어 있을수록 제목 점수를 더(×2 ~ ×4) |

도서 **종류 · 분야 자동 판단**(`profileBook`)은 67권에서 사람이 보고 맞췄다: 법규는 `제1조(목적)` 꼴 표제 밀도로(법 조문을 인용만 한 자기계발서는 법규가 아님), 표(xlsx · csv)는 목록, pptx 는 강의, 글꼴 인코딩이 깨진 PDF(흔한 낱말이 1000자당 3개 미만)는 '본문 깨짐', 일반 도서(프로그래밍 · 심리학)는 우연히 섞인 제어 낱말로 분야를 매기지 않음.

### 3차 — 현장 기기 · 국제 규격 학습과 '답변 상자'
2026-10-24 인터넷 자료(ASME B40.100 · PTC 19.3 TW-2016 · API 598/600/6D · ANSI/FCI 70-2 · IEC 60751/60584 · NAMUR NE 43/107 · EN 15714-2 · ISO 5210/5211 · API 611/612/616/670 · API RP 551~555 · IEC 61131-3 · ISA-18.2/101 소개 자료와 제작사 기술 자료)로 써모웰 · 압력/온도 게이지 · 차단 밸브류(게이트 · 글로브 · 볼 · 버터플라이 · 체크) · MOV · 레벨 스위치 · 계장 스위치 개념 7개를 더하고(개념 49개), 규격(standards) 개념에 국제 코드 번호를 보강했다. 같은 표현이 두 개념에 있던 것(써모웰 ↔ 온도 측정 심화, 게이트 밸브 ↔ 밸브 설계 심화 …)은 전용 개념 쪽만 깨우도록 정리. 순위 지표는 변화 없음(조정용 0.895 · 시험용 0.917 · 발전 0.726).

'💬 답변' 상자는 AI 모델 없이 ① 폴더 도서 원문 인용(도서 번호 · 쪽)과 ② 내장 학습 지식(`kb.js notes`, 출처 표시)을 나눠 보여 준다. 인용 문장은 **질문의 주제 개념**(첫 개념 · 기기 개념) 의 가중치 .9 이상 표현이 실제로 들어 있는 문장만 고른다 — 보조 개념(설계 산출물 · 인터록)의 표현('installation drawing', 'cause and effect')으로 엉뚱한 문장이 인용되던 것을 막음. 시험 도서에는 규격 원문이 없어 폴더 근거는 교재 · 매뉴얼 문장이 주로 나온다.

### 아직 남은 한계
- 사전 · 용어집에 없는 다른 말(동의어)은 넓히지 못함 — AI 모델(의미 검색)을 쓸 수 없는 환경이라 사전 방식. 자주 쓰는 말이 빠지면 `index.html` 의 `THES_ADD` · `GLOSS_SRC` 에 한 줄 추가.
- 시험 도서에 **한국어 계장 전문서가 적음** (공개 자료를 받을 수 있는 곳이 막혀 있었음) — 실제 부서 도서로 질문 20~30개만 라벨을 달아 `sim.js` 로 한 번 더 확인하면 좋음.
- 라벨이 성긴 주제(레벨 · 유량)는 nDCG 가 0.6 안팎 — 대부분 '1위는 맞고 2~5위 순서' 차이.
- 발전 · 플랜트 묶음(0.726)은 시험 도서의 한계가 큼 — 보일러 연소 제어 · DCS 캐비닛 · 케이블 스케줄 · 제어밸브 사이징 질문은 정답이 될 책이 폴더에 없다. 실제 부서 도서(터빈 · HRSG 벤더 매뉴얼 · 설계 기준서)로 `queries_pp.json` 형식의 질문 20~30개를 라벨해 한 번 더 조정하면 좋음.

## 4. 다시 해 보기

```
python server.py --root <시험 운영폴더> --port 8790 --plaza-port 0       # books_api 연결된 server.py
curl -X PUT -H "Content-Type: application/json" -d "{\"root\":\"<도서 폴더>\"}" http://127.0.0.1:8790/api/books/root
node sim.js index        # 색인 (63권 ≈ 2분)
node sim.js dev          # 조정용 48개
node sim.js test         # 시험용 20개 (V=1 이면 질문별 해석 · 상위 3권)
node sim.js pp           # 발전 · 플랜트 15개
node sim.js tune 300     # 가중치 후보 → CFG='{"…"}' node sim.js test 로 확인 → index.html CFG 에 반영
```
실제 부서 도서로 시험하려면 `queries_test.json` 형식(질문 → {파일 이름 일부: 등급})으로 질문을 만들면 된다.
