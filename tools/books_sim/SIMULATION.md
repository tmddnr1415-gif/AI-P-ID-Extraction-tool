## 2. 질문

- **조정용 48개** (`queries_dev.json`): 주제 12개 × 말투 4가지 — 짧은 말 · 대화체 · 영어 · 섞어 쓰기
  예) `Transmitter 관련 도서` / `트랜스미터에 대해 설명된 책 있어?` / `압력전송기 영점 조정은 어떻게 해?` / `HART로 PV 값 읽는 방법` / `ladder diagram 배우고 싶어` / `계장 도면 기호 읽는 법`
- **시험용 20개** (`queries_test.json`, 조정에 쓰지 않음): 다른 주제 · 다른 분야 — `열전달 전도 대류`, `리눅스 명령어 배우기`, `무선 송신기 radio transmitter 시험 문제`, `IEC 62443 존과 컨듀잇`, `계량법 검정 기준` …

지표: **nDCG@10** (상위 10권 순서 품질, 1 = 완벽) · **MRR** (가장 관련 높은 책이 몇 번째에 나오나, 1 = 1위) · **상위 5 방해 도서** 수.

### 무엇이 문제였고 어떻게 고쳤나
| 문제 (처음 결과) | 고친 방법 |
|---|---|
| `트랜스미터에 대해 설명된 책 있어?` 의 '있어', `오리피스로 유량 재는 원리` 의 '재는' 같은 말까지 검색 → 한글 자기계발서 · 소설이 위로 | 대화체 불용어 · 조사 · 짧은 동사 꼴 제거 (사전 낱말은 남김: '제어' 등). 뺀 말은 화면에 "검색에서 뺀 말" 로 보여 줌 |
| '원리 · 방법 · 종류 · 설치 · 예제' 가 주제처럼 같은 무게 | **관점**(알고 싶은 내용) 11가지로 따로 — 낮은 가중치로 그 내용이 있는 쪽만 조금 앞으로, 책을 거르지 않음 (화면에 🎯 표시) |
| '센서 · 계장' 처럼 넓은 말이 주제를 덮음 | 더 구체적인 주제가 있으면 넓은 말은 보조로 |
| 한글 질문 → 영어 책을 못 찾음 (`열전달 전도 대류` → 0점) | **한영 일반 기술 용어집**(약 250개): 사전에 없는 낱말도 번역어로 함께 찾음 (영어 → 한글도). 화면에 `열전달 (heat transfer)` 처럼 표시 |
| `제어밸브 포지셔너` 에서 '밸브 포지셔너' 가 '밸브' 를 먼저 먹어 제어밸브를 못 알아봄 | 원래 질문에서 겹치는 표현을 모두 개념으로 |
| `SCADA 해킹 대응`, `탱크 수위`, `계장 도면 기호`, `SIL 등급` 등 사전 빈틈 | 사전 보강 (수위 · 해킹 · 도면 기호 · 태그 · SIL 등급 · 2oo3 · 영점 · 비상정지 · OPC · 로드셀 · DAQ · 온도 조절기 · 계량 법규 …) |

| 스캔본(글자 없음)은 '계장 분야 아님' 으로 감점 | 글자가 거의 없는 책은 분야 점수 중립 → 파일명으로 잘 찾힘 |

### 아직 남은 한계
- 사전 · 용어집에 없는 다른 말(동의어)은 넓히지 못함 — AI 모델(의미 검색)을 쓸 수 없는 환경이라 사전 방식. 자주 쓰는 말이 빠지면 `index.html` 의 `THES_ADD` · `GLOSS_SRC` 에 한 줄 추가.
- 시험 도서에 **한국어 계장 전문서가 적음** (공개 자료를 받을 수 있는 곳이 막혀 있었음) — 실제 부서 도서로 질문 20~30개만 라벨을 달아 `sim.js` 로 한 번 더 확인하면 좋음.
- 라벨이 성긴 주제(레벨 · 유량)는 nDCG 가 0.6 안팎 — 대부분 '1위는 맞고 2~5위 순서' 차이.

## 4. 다시 해 보기

```
python server.py --root <시험 운영폴더> --port 8790 --plaza-port 0       # books_api 연결된 server.py
curl -X PUT -H "Content-Type: application/json" -d "{\"root\":\"<도서 폴더>\"}" http://127.0.0.1:8790/api/books/root
node sim.js index        # 색인 (63권 ≈ 2분)
node sim.js dev          # 조정용 48개
node sim.js test         # 시험용 20개 (V=1 이면 질문별 해석 · 상위 3권)
node sim.js tune 300     # 가중치 후보 → CFG='{"…"}' node sim.js test 로 확인 → index.html CFG 에 반영
```
실제 부서 도서로 시험하려면 `queries_test.json` 형식(질문 → {파일 이름 일부: 등급})으로 질문을 만들면 된다.
