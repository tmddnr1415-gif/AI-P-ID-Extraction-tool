# Windows x86_64 · Python 3.11 전용 — 오프라인(사내 PyPI 차단) 이관용
#
# `requirements.txt` 와 다른 점은 **하나**입니다: `uvicorn[standard]` 를 쓰지 않고
# 그 부가 의존을 풀어 적었습니다.  이유는 pip 의 동작이고, 실측했습니다:
#
#   pip download --platform win_amd64 는 **환경 마커를 대상 플랫폼으로 다시
#   평가하지 않습니다.**  `uvloop` 의 마커가 `sys_platform != "win32"` 라
#   리눅스에서 받으면 uvloop 이 여전히 필수로 남고, uvloop 은 win_amd64 휠이
#   없으므로 다음 오류로 **전체 다운로드가 실패**합니다:
#     ERROR: Could not find a version that satisfies the requirement
#            uvloop>=0.15.1; sys_platform != "win32" ... (from versions: none)
#
# uvicorn[standard] 의 부가 의존 6개 중 Windows 에서 빠지는 것은 **uvloop 뿐**이고
# (uvicorn 0.52.3 의 Requires-Dist 로 확인), 나머지 다섯은 Windows 에도 그대로
# 적용됩니다.  uvloop 이 없어도 uvicorn 은 asyncio 기본 루프로 돕니다 —
# `app/desktop.py` 도 `uvicorn.run(app, ...)` 로 부를 뿐 `loop=` 를 지정하지
# 않습니다.  성능 차이는 이 앱에서 의미가 없습니다: 요청은 로컬 1인 사용이고
# 시간은 전부 PyMuPDF 파싱(58장 약 3분 40초)에 듭니다.
#
# 설치 (회사 PC · 오프라인):
#   py -3.11 -m venv .venv
#   .venv\Scripts\Activate.ps1
#   pip install --no-index --find-links wheels -r requirements-win.txt
#
# 버전은 개인 PC(리눅스)에서 실제로 돌린 것과 같게 고정했습니다.  고정하지
# 않으면 회사 PC 가 오프라인이라 "설치는 됐는데 버전이 다른" 상태를 만들 수
# 있고, 그러면 지문 대조가 의미를 잃습니다.
