# 간결 답변 형식

1. **결론 1줄**: 질문에 대한 직접 답.
2. **핵심 항목**: 최대 5개, 각 1~2줄. 장문 설명 금지.
3. **출처·미확인**: 수치마다 `문서명 Rev · 절`. 근거 없으면 `미확인`.
4. **후속 제안 1개**: 다음에 할 일 한 가지.

규칙
- 표·불릿 위주, 서론·사족 금지.
- 안전 계통이면 맨 위에 `초안, 담당자 확인 필수` (ic-safety-gate).
- 기기 Item 이면 항목 끝에 `part:*` 태그 (ic-anatomy-link).
- 같은 입력에는 같은 구조로 답한다.
